Ayla 1.0.41 更新内容

【悬浮球：背景真正可点穿（手机 / 电脑）】
- 上下两端的悬浮球：现在**只有球本身可点击**，球以外的区域完全穿透，
  不会再挡住下面应用的操作。
- 电脑端改为逐像素穿透（球的圆形、辉光边缘都算准），不再是一个方块区域。

【悬浮球交互：重做拖动】
- 去掉了上一版「按下时窗口临时铺满屏幕」的做法 —— 那是导致画面截断、
  球跳动、拖不动的根源。
- 现在窗口始终贴合球体，拖动由球自己算位置，不再有跳动与裁切。

【说明】
- 本版只改悬浮球（穿透 + 交互）。
- 电脑端直播小窗的拖动/缩放、手机端直播小窗、全屏比例等其余项目在后续版本逐个推进。

建议所有用户更新。
