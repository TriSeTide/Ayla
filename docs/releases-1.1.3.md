# Ayla 1.1.3 更新内容

本次为累计多轮修复的合并版本（上次发版 1.1.2 之后的全部改动）。

## 修复：手机端进开播页直接闪退（重要）

- 修复手机端从直播列表点「添加直播」进开播页时**直接闪退**的问题。
- 根因是悬浮球/直播小窗的保活前台服务存在竞态：服务还没创建就被拆掉，
  系统判定超时后直接杀掉进程。现已保证「起服务之后一定先完成前台化再收尾」。
- 同一问题也解释了此前偶发的「点进开播页闪退」「球出来了但 App 随后消失」。

## 修复：悬浮球显示与跳转

- **悬浮球改为只看状态**：只要当前在语音房、或在开播，就一直显示对应的球，
  不再根据你停在哪个页面而隐藏。此前在语音房内、开播界面里球会消失。
- **点直播球固定回到开播页**：以前冷启动先落进自己开播的直播间后，点球会跳回
  自己直播间的观看页；现在只要你在开播，点球一律回到自己的开播控制台。
- 点语音球仍是回到你进入时的那个房间（群内语音回群场景）。

## 修复：直播没有声音

- 修复 Web 端直播**从头到尾没有声音**的问题（画面和弹幕正常、也无报错）。
- 原因：为满足浏览器自动播放策略，起播时是静音启动的，但代码里从没把它恢复
  成有声，且界面上没有音量键 —— 「起播手段」被当成了「最终状态」。
- 现在直播会按你的偏好自动恢复声音，并新增音量开关。

## 新增：直播音量开关（观众端 / 开播端默认值分开）

- 观众端（看别人的直播）**默认有声**；开播控制台（自己的播）**默认静音**。
- 两端偏好**分开保存**：你在自己开播时静音，去看别人直播不会受影响，反之亦然。
- 开播端默认静音是因为主播自己那一路流会回环到本机播放器，默认出声等于把
  自己的声音延时回授一遍（回声/啸叫）。
- 观众端：直播间左下角新增音量键；手机端小窗左上角也有音量键。
- 音量偏好跨直播间保留，重启 App 不丢。

## 修复：直播卡顿（Windows 与 Web 双端）

经排查，卡顿的**主要原因是你所在 WiFi 的信号质量**（换信道后分片下载耗时从
p50 3.11 秒降到 4 毫秒）。此外本次还修掉了排查中确认的 5 项**独立的代码缺陷**：

- 修复「播放器出过一次画面后，卡死检测永久失效」—— 此前上游断流 151 秒，
  两端都没有触发任何重建。
- 修复「判死阈值低于正常分片耗时」—— 正常网络抖动会被误判成故障并触发重建，
  把 1 秒抖动放大成卡顿 + 黑屏。阈值已与另一端对齐。
- 修复 SRS 的 120 秒清理策略造成推流中断后出现约 30 秒的 404 黑洞。
- 直播分片级故障（分片 404 / 超时 / 解析失败）改为**可观测上报**：
  以前这类错误被完全丢弃，画面卡住但界面没有任何信号。

## 修复：登录后不自动检查更新

- 修复电脑端与手机端「登录后不弹更新提示」的问题（冷启动主路径漏接线）。
- 现在每次启动/回到前台都会检查一次；换账号登录后也会重新检查。
- 手机端：强制更新弹窗打开时，按返回键**不再能绕过**。
- 电脑端：强制更新时，自绘标题栏的关闭键会被锁定，**不再能绕过**更新。
- 版本号读取失败时不再误判成「有新版本」反复弹窗。

## 修复：直播观看名单与相关交互

- 修复观看名单里**点头像不跳转**的问题（点行只关弹层）。
- 修复观看名单读取失败时「重试」键完全没反应。
- 一并修掉同类的三处「点了没反应」：
  - 消息里 @提及的胶囊点击无反应；
  - 收藏页 / 搜索结果的消息卡里 @胶囊点击无反应；
  - 直播分片错误的静默失败。

## 说明

- 本次为**客户端 + 服务端**配套更新，建议所有用户更新。
- Windows 端涉及窗口与原生层改动，更新后需**完全退出并重新打开**才会全部生效。
- 直播卡顿若仍存在，优先检查 WiFi 信道干扰（本机实测 ch48 → ch149 差异极大）。
