## 二、技术架构

### 2.1 WebSocket 推送流程

```
用户 A 操作（创建/删除）
    ↓
Django View 持久化到数据库
    ↓
Service Layer broadcast_* 函数
    ↓
Django Channels Layer (group_send)
    ↓
ChatConsumer 事件处理器方法
    ↓
WebSocket (send_json) → 所有在线用户
    ↓
前端 ChatWSClient.dispatch()
    ↓
Zustand Store.upsert/remove()
    ↓
React 组件自动重渲染
```

### 2.2 图片加载优化架构

```
第一次请求：
浏览器 → Django → MinIO → Django → 浏览器
         (写入 Cache-Control 和 ETag)
           ↓
      浏览器缓存 1-2 小时

第二次请求（缓存未过期）：
浏览器直接从磁盘缓存读取（200 disk cache）

第三次请求（缓存过期）：
浏览器 → Django (检查 If-None-Match)
           ↓
      ETag 匹配 → 返回 304 Not Modified
           ↓
      浏览器复用旧缓存
```

### 2.3 前端数据加载优化架构

```
用户登录
    ↓
main.tsx: Promise.all 并发预加载
    ↓
会话、语音房、直播间列表 → Zustand Store
    ↓
用户打开任意弹窗
    ↓
VisibilitySelector: 检查数据是否就绪
    ↓
就绪：直接使用
未就绪：显示骨架屏 → 自动加载 → 显示数据
```
