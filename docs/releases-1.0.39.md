Ayla 1.0.39 更新内容

【悬浮球：背景可以点穿了（手机 / 电脑）】
- 修复上一版悬浮球「一大片区域点不了」的问题。
  现在只有**球本身**可点击，球以外的区域会正常落到下面的应用上。

【手机端悬浮球：交互修好】
- 修复点不开、收不起、拖不动的问题。
- **App 在后台时点悬浮球可以直接唤起 Ayla**。

【手机端直播小窗：换回原来那个】
- 上一版打开的是另一个新窗口，现已删除。现在**就是原来那个 168×94 的小窗卡片**，
  可以在应用外显示、可拖动、可双指缩放。

【电脑端直播小窗：可拖动、可缩放】
- 可以拖到屏幕任意位置。
- 鼠标移到小窗边缘可以调整大小（等比缩放，画面不拉伸）。
- 小窗播放区以外同样不挡点击。

【手机端全屏：画面不再拉伸】
- 修复全屏时画面被拉成正方形的问题。现在保持原始比例，多余部分留黑边。

【说明与已知限制】
- 苹果 iOS 受系统限制，不支持跨应用悬浮窗，功能仍留在应用内。

建议所有用户更新。
