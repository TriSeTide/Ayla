Ayla 1.0.8 更新内容

- 聊天里的「分享」卡片现在可以点了：点一下直接跳到分享的内容，
  分享的是本群的内容就留在群里打开，分享的是别的内容就跳到对应页面。

- 收藏页点卡片可以直接跳回原内容；跳过去之后按返回键能回到收藏页
  （以前是直接退出）。收藏的聊天消息即使是很早以前的，也能自动翻到并定位。

- 全站头像都能点进个人主页了：
  · 直播间的主播头像、弹幕里的头像
  · 语音房成员的头像
  · 帖子卡片的作者头像（群里、搜索里、收藏里都能点）
  · 会话列表、消息中心、评论、群成员等原有入口保持不变

- 聊天界面的头像长按：
  · 长按别人的头像 0.5 秒 → 自动在输入框里 @这个人
  · 点一下头像 → 进对方个人主页
  · 双击头像 → 戳一戳（原有）

- 从分享消息点进其他群的语音房 / 直播间时，现在能正常进入观看
  （以前会卡在加载中）。

建议所有用户更新。
