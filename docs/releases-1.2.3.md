# Ayla 1.2.3 更新内容

本次修复聊天界面里气泡"忽宽忽窄"的问题。

## 修复：气泡宽度不再跳动

- 之前屏幕较窄时，自己的消息气泡会被左侧的工具栏（收藏/引用/撤回）
  和发送中的转圈挤得很窄；等 2 分钟撤回键消失、上传结束后，
  气泡才突然变回正常宽度。
- 现在**消息刚发出时是什么宽度，之后就一直是什么宽度**，
  不会再变宽或变窄。

## 改进：窄屏工具栏改为图标

- 屏幕不够宽时，工具栏按钮只显示图标（收藏/引用/撤回），
  不再把文字挤成竖排。
- 屏幕够宽时仍然是图标 + 文字，和以前一样。

## 改进：发送中的进度不再占地方

- 上传进度和取消按钮现在浮在气泡左侧的固定位置，
  不再挤压气泡本身。

## 说明

- 群聊和私信都已生效。
- 完全退出应用后重新打开，新版本才会完全生效。
