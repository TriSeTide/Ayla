# 爱莉前端对接层撤下清单

> 状态：**执行中**。目标是把 Ayla web 与 Flutter 里「界面上显示爱莉的那一层」全部撤下，为后续按新需求重做让位。
> 前提：**当前没有真实用户**，可以无兼容负担地删。
> 留档原则：视觉身份组件的**源码**保留在仓库（不删文件以外的归档），但**界面上不再出现**。
> 关联：后端侧见 [REQUIREMENTS.zh.md](./REQUIREMENTS.zh.md) 与 §13 删除清单。

## 0. 三层分离（判定每个文件属于哪层）

| 层 | 含义 | 处置 |
|---|---|---|
| ① 功能对接层 | 调用 `/api/v1/elysia/*`、处理 `elysia.reply` 事件、爱莉语音通话编排、profile 拉取与 provider | **全删** |
| ② 视觉身份层 | `AylaAvatarCore.elysia`、`--bubble-elysia`、`elysiaBubbleBorder`、`.elysia-entry` 样式族 | **源码留档，界面不挂载** |
| ③ 测试夹具 | `username:'elysia'`、`nickname:'爱莉'` 之类假数据 | 随所属测试处理，不影响功能 |

判定口诀：**它是否发起网络请求、是否消费爱莉事件、是否持有爱莉会话身份** → 是则①。

## 3. 需要拍板的一处

`MessageBubble` / `message_list` 的「爱莉气泡样式分支」：数据来源（`elysiaUserId`）删除后，分支恒不成立。
- 方案 A（默认）：保留分支代码 + 注释「等待新对接」，避免下次重做又要从 git 历史里捞。
- 方案 B：一并删除分支，只留样式 token。

**本文按方案 A 执行**，除非另有指示。
