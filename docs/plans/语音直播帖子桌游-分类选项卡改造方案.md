## 1. 需求确认

### 1.1 四个页面的选项卡

| 页面 | 选项卡（按序） | 过滤维度 |
|---|---|---|
| 语音 /voice | 全部 / 公开 / 好友 / 有人 / 我的 | visibility；member_count>0；owner_id=我 |
| 直播 /live | 全部 / 在播 / 公开 / 好友 / 停播 / 我的 | status=live；visibility；status≠live；is_owner |
| 帖子 /posts | 全部 / 热门 / 公开 / 好友 / 我的 | view_count 排序；visibility；is_author |
| 桌游 /games | 全部 / 公开 / 好友 / 我的 / 等待中(占位) / 对局中(占位) | visibility；is_owner；status（占位） |

### 1.2 排序规则

- 所有选项卡**保持原页面排序**（directory store 的 sortItems 逻辑不变）：
  - 语音：有人区优先（member_count>0）+ last_occupied_at 倒序（sortVoiceChannels）
  - 直播：在播优先 + started_at（sortLiveChannels）
  - 桌游：created_at 倒序
  - 帖子：feed 原顺序
- **唯一例外**：帖子「热门」按 view_count 降序（前端对已加载数据排序）

### 1.3 布局与动效

- 四个页面改为 `directory-page` 布局（与收藏/搜索一致）：
  - **左侧栏复用**：直接复用收藏/搜索的 `DirectoryFilters` 组件与样式（**224px** 玻璃侧栏，`auroraqua-sidebar-in` 从左滑入），零改动
  - **右侧内容区右移但布局不变**：内容区从原「全宽居中」右移到侧栏右侧，占满剩余宽度（flex: 1 1 0）；**内容区内部网格布局保持原样**——列数断点（语音/直播 2/3/4 列、帖子单列/双列瀑布流、桌游 2/4 列）、卡片样式、间距一律不动，只去掉 max-width 居中容器
  - 窄屏：顶部水平选项卡（DirectoryFilters，`auroraqua-panel-from-top` 从顶滑入）+ 内容区
- **不用返回键**（DirectoryFilters 的 leading 不传）
- **上方装饰**：各页面 decor 图标（**64px**，rotate -8deg，opacity 0.42）+ header（kicker + 标题 + 统计）：
  - 语音 IconMic / 直播 IconVideo / 帖子 IconPost / 桌游 IconGame（收藏 IconHeart、搜索 IconSearch 已有）
  - header 统计：语音「X 房间在线 · Y 人在聊」（directory.total / totalMemberCount）、直播「X 直播间 · Y 在播」、帖子「X 条帖子」、桌游「X 个房间」；无统计数据的页面可只放 kicker + 标题
- **6 个页面装饰标志全部改粉色**：`.directory-filter-decor` 的 `color: var(--ice-500)` → 粉色（`--pink-500: #f17eb3`，以 design.md 为准）——**已完成**

> 待确认点：内容区占满后，网格列数断点不变 → 宽屏下卡片会随容器变宽（如 1920 屏 4 列 ≈ 400px/卡）。若希望卡片尺寸不变，需保留内容区 max-width（如 1200px 居中于侧栏右侧）。默认按「占满 + 列数断点不变」实施。

## 2. 技术方案

### 2.1 复用组件

- `DirectoryFilters`（`web/src/components/DirectoryFilters.tsx`）直接复用，零改动：
  - 宽屏垂直侧栏 / 窄屏水平顶栏自动切换（narrow prop）
  - 选中项 AuroraquaNavHighlight 高亮
  - 键盘方向键导航（宽屏上下 / 窄屏左右）
- 各页面传参：`id`（useId）、`label`、`options`、`value`、`narrow`、`className`、`buttonClassName`、`decor`（图标）、`onChange`；**不传 leading**（无返回键）

### 2.2 CSS 选择器扩展（directory-filters.css）

当前选择器只覆盖收藏/搜索：

```css
.directory-page:is(.search-page, .favorites-page) { ... }
```

需扩展为 6 个页面（或改用通用类）。四个新页面根元素类名：`voice-hub` / `live-hub` / `posts-hub` / `games-hub`，需给根元素同时加 `directory-page` 类。

注意协调：`voice.css` / `live.css` / `posts.css` / `boardgame.css` 中现有 `.voice-hub` 等规则（如 voice-hub 的 `max-width: 1200px` 居中网格、padding-bottom 68px 避让 FAB）需与 directory-page 布局合并，避免冲突。

### 2.2.1 滚动容器迁移（关键，窄屏顶栏固定的前提）

四个页面根元素（`.voice-hub`/`.live-hub`/`.posts-hub`/`.games-hub`）**现在是滚动容器**（`height:100% + overflow-y:auto`）。接入 `directory-page` 布局后：

- 根元素加 `directory-page` 类 → 变为 `height:100% + overflow:hidden + flex column`（directory-filters.css 规则）
- 滚动**必须迁移到 `.directory-content`**（`overflow-y:auto`，directory-filters.css 已定义）
- 根元素原有的 `overflow-y:auto` 必须移除/被覆盖，否则出现双层滚动或窄屏顶栏跟随滚动
- 各页面的 `onScroll`（分页加载/滚动恢复）从根元素改挂到 `.directory-content`

### 2.2.2 窄屏顶栏细节（老生常谈，DirectoryFilters 自带，接入即生效）

- **顶栏固定不跟随滚动**：窄屏 `.directory-filters` 是 `flex:none` 顶栏，内容区 `.directory-content` 是独立滚动容器——顶栏天然固定。前提是滚动已迁移（见 2.2.1）
- **顶部滑入动画**：`auroraqua-panel-from-top`（从顶滑入，directory-filters.css 窄屏媒体查询已定义）
- **横向滑动**：`touch-action: pan-x` + 横向滚动（已定义），选项卡多时可横滑
- **内容区避让 FAB**：窄屏 `.directory-content` `padding-bottom: calc(68px + env(safe-area-inset-bottom))`（已定义），原根元素 padding-bottom 可移除
- **reduced-motion**：动画关闭（已定义）

### 2.3 各页面接入

#### 语音 VoiceHubPage（web/src/pages/VoiceHubPage.tsx）

- 根元素：`voice-hub` + `directory-page`，包一层 `directory-body`
- 加 `DirectoryFilters`：options = 全部/公开/好友/有人/我的，decor = IconMic
- 过滤（前端，量级小）：
  - 公开：`visibility === "public"`
  - 好友：`visibility === "friends"`
  - 有人：`member_count > 0`
  - 我的：`owner_id === currentUser.id`（useAuthStore）
- 排序：保持 directory 原排序（sortVoiceChannels 不变）
- 内容区：`voice-channel-list` 去掉 `max-width: 1200px` 居中容器，占满侧栏右侧剩余宽度；**网格列数断点（窄 2 / 宽 3 / 1440+ 4 列）与卡片样式不变**
- 注意：进房路由（/voice/:channelId）与房内态逻辑不动；仅大厅列表接入选项卡

#### 直播 LiveHubPage（web/src/pages/LiveHubPage.tsx）

- 根元素：`live-hub` + `directory-page` + `directory-body`
- 加 `DirectoryFilters`：options = 全部/在播/公开/好友/停播/我的，decor = IconVideo
- **移除现有「只看在播」开关**（live-hall-filter），由「在播」tab 取代
- 过滤：
  - 在播：`status === "live"`
  - 停播：`status !== "live"`（idle）
  - 公开/好友：visibility
  - 我的：`is_owner === true`
- 排序：保持原排序（sortLiveChannels 不变）

#### 帖子 PostsHubPage（web/src/pages/PostsHubPage.tsx）

- 根元素：`posts-hub` + `directory-page` + `directory-body`
- 加 `DirectoryFilters`：options = 全部/热门/公开/好友/我的，decor = IconPost
- **移除现有「我的帖子」链接**（posts-hub-head），由「我的」tab 取代
- 过滤：
  - 公开/好友：`visibility`
  - 我的：`is_author === true`（前端过滤已加载数据；不重新拉 scope=mine）
- 排序：
  - 全部/公开/好友/我的：保持 feed 原顺序
  - 热门：`view_count` 降序（前端对已加载数据排序）
- 内容区：`posts-feed` 去掉 `max-width: 680px` 居中容器，占满侧栏右侧剩余宽度；**瀑布流断点（>1024px 双列）与卡片样式不变**

#### 桌游 GamesHubPage（web/src/pages/GamesHubPage.tsx）

- 根元素：`games-hub` + `directory-page` + `directory-body`
- 加 `DirectoryFilters`：options = 全部/公开/好友/我的/等待中/对局中，decor = IconGame
- 过滤：
  - 公开/好友：visibility
  - 我的：`is_owner === true`
  - 等待中/对局中：**占位**（用户明确未实现；tab 渲染可切换，过滤逻辑可留 TODO 或简单实现 status 过滤——status 字段现成，实现成本一行，由实施时与用户确认）
- 排序：保持原排序（created_at 倒序）

### 2.4 装饰标志改粉色

- `directory-filters.css` `.directory-filter-decor { color: var(--ice-500) }` → 粉色
- 影响 6 个页面：收藏（IconHeart）、搜索（IconSearch）、语音（IconMic）、直播（IconVideo）、帖子（IconPost）、桌游（IconGame）
- 粉色取值以 design.md 为准（token 速查：`--pink-500: #f17eb3`）

### 2.5 状态保持

- 选项卡切换用 URL search 参数（?type=xxx，与收藏/搜索一致），支持返回/刷新保持
- 各 tab 独立滚动位置（useScrollRestore，scope 含 filter）
- 切换 tab 时内容区重挂载（key=scope），进入时 `directory-content-in` 淡入上移动画（已有）

## 3. 验收标准

1. 四个页面宽屏：左侧 224px 玻璃侧栏从左滑入，内容区右移到侧栏右侧占满，无 max-width 居中残留；内容区内部网格列数断点与卡片样式不变
2. 四个页面窄屏：顶部水平选项卡从顶滑入（auroraqua-panel-from-top），**顶栏固定不随内容滚动**（滚动容器是 .directory-content，根元素无 overflow-y:auto 残留、无双层滚动）
3. 各 tab 过滤正确（公开/好友/有人/在播/停播/我的/热门/等待中/对局中）
4. 排序：除帖子热门按 view_count 降序外，全部保持原排序
5. 无返回键；decor 图标正确且为粉色（6 页面一致）
6. 语音进房/直播进房/桌游进房/帖子详情路由与房内态不受影响
7. 窄屏内容区底部避让 FAB（padding-bottom 68px 生效）；reduced-motion 下动画关闭
8. 现有测试不破坏；新增 tab 切换/过滤契约测试
9. design.md 同步增补「分类选项卡」规范（DirectoryFilters 覆盖 6 页面）
