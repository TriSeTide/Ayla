# Ayla 聚合主页与多端布局需求文档

> 本文以**前端操作流**为主线描述需求（以用户原始操作描述为基准，逐句展开，交互细节精确到动画方向与点击语义）。
> **窄屏与宽屏是一等公民的两种形态**：窄屏（≤768px）操作流是本文主线；宽屏（>768px）是独立桌面形态（见 §4）。本期只做 **Web 前端**（窄屏靠响应式适配），不做移动端 App。
> 视觉规范唯一事实源：`Ayla/docs/design.md`（千禧冰樱 / Y2K Frost），所有界面必须遵守其 token、组件配方与 Do/Don't。

## 1. 背景与目标

当前 Ayla Web 端聊天、语音、直播是三个平级独立页面，没有统一的"家"。本阶段把产品重构为**以群聊为主页聚合体**的社区应用：主页 = 我的群聊集合；每个群聊是一个"小世界"（群内自己的聊天、直播、语音房、帖子、桌游室）；语音/直播/帖子/桌游四个一级模块是跨群 + 公开 + 好友范围的聚合视图；消息（私信、好友/群申请）独立入口；搜索、个人界面、收藏等辅助能力补齐。

## 2. 名词与范围约定

| 名词 | 含义 |
|---|---|
| 窄屏 | 视口 ≤768px 的移动式布局（本期 Web 端主要形态） |
| 宽屏 | 视口 >768px 的桌面布局 |
| 主页 | 一级模块"主页"。**窄屏** = 我的群聊集合（卡片/列表网格）；**宽屏** = Discord 式三列群聊界面（服务器栏+频道侧栏+内容区），无网格中间层 |
| 底部导航栏 | 窄屏底部固定五 tab：语音、直播、主页、帖子、桌游（下文简称"底栏"） |
| 群聊场景 | 进入某群后，群内部的聊天 / 直播 / 语音 / 帖子 / 桌游五个子界面 |
| 一级 tab 界面 | 语音/直播/帖子/桌游四个跨群聚合视图（公开 + 好友 + 已加入群） |
| 可见范围 | 房间/帖子/直播间的可见性：公开 / 好友 / 群成员（本期创建默认公开） |
| FAB | 右下角浮动加号按钮 |
| 群信息界面 | 群资料、成员、申请审批、管理、退出/解散群 |

## 3. 窄屏操作流（核心需求）

### 3.1 主页（群聊集合）

**布局**：

```
┌─────────────────────────────┐
│ (头像)   [ 搜索框…… ]   (≡) │  ← 顶栏
├─────────────────────────────┤
│  ┌───────┐   ┌───────┐      │
│  │ 封面  │   │ 封面  │ ●    │  ← 群聊卡片（轮播封面 + 未读点）
│  │ 群聊  │   │ 群聊  │      │
│  └───────┘   └───────┘      │
│  ┌───────┐   ┌───────┐      │
│  │ 群聊  │   │ 群聊  │      │
│  └───────┘   └───────┘      │
│            · · ·            │  ← 分页指示
│ (消息)●                (+)  │  ← 左下消息入口 / 右下 FAB
├─────────────────────────────┤
│ 语音   直播  [主页] 帖子 桌游│  ← 底部五 tab
└─────────────────────────────┘
```

- R-H1 顶栏左侧为当前用户**头像**，点击进入**个人界面**（§3.7）。
- R-H2 顶栏中部为**全局搜索框**，点击进入搜索界面（§3.8）。
- R-H3 顶栏右侧为**"三"更多按钮**，点击弹出功能菜单：**个性化、扫一扫、收藏**（本期至少占位这三项）。
- R-H4 主体为**我加入的群聊**集合，支持两种布局，用户可开关切换，选择持久化：
  - **卡片布局**：两列网格。卡片上半部分为大封面区域，以**轮播图**播放该群的动态封面（群内直播间封面、帖子图片、桌游封面等，按时间新→旧）；卡片下方显示群头像 + 群名称。
  - **列表布局**：类似 QQ 会话列表，每行显示群头像、群名称、新消息预览（最新一条消息摘要）。
- R-H5 卡片与列表项上的**状态角标**：未读消息红点（带数量）；麦克风图标（群内有进行中的语音房）；直播图标（群内有正在直播的直播间）；桌游图标（群内有进行中的桌游室）。
- R-H6 卡片布局内容多时**分页/加载更多**（线框图中 `· · ·` 指示）。
- R-H7 左下角**消息入口**（圆形按钮，带未读红点），点击进入消息界面（§3.6）。
- R-H8 右下角 **FAB 加号**，点击弹出创建弹窗，动作随当前场景切换（§3.5）。
- R-H9 空态与加载态：未加入任何群 → 空态引导（"创建你的第一个群"主 CTA + "搜索发现群"副入口）；加载中 → 玻璃质感骨架屏（禁止白屏）；失败 → 错误文案 + 重试按钮，区分"无内容"与"加载失败"。

### 3.2 底部导航与 tab 切换

- R-N1 底部固定五 tab：**语音、直播、主页（选中态凸起/高亮）、帖子、桌游**。
- R-N2 五个 tab 之间支持**左右滑动手势切换**（与点击 tab 等效），滑动时页面横向跟随。
- R-N3 tab 切换保留各 tab 内部状态（滚动位置、已进入的子界面栈不丢失，返回时可恢复）。
- R-N4 未读红点刷新：消息入口/群卡片红点由 `me/badges/` 与会话 unread_count 驱动；**纯 WS 事件驱动**（任务 08：私信/申请/邀请/群@我 事件触发 fetch；WS 重连后补拉对账；无周期轮询，原 30s 断线降级已删除）；红点变化不打断当前操作。

### 3.3 进入群聊（群聊场景容器）——动画方向精确描述

点击主页群卡片/列表项进入该群：

- R-G1 **转场动画（底栏整体上移到顶部）**：底部导航栏**整体向上滑动到视口顶部**（不是滑出底部——动画终点是顶部，为下方弹出输入框腾出底部空间），"主页"中央位置的 tab 字样**形变/切换为群头像**。上移后的顶部导航条保持：`语音 | 直播 | 群头像 | 帖子 | 桌游`。群聊场景中，四个 tab 点击 = 切换到该群对应子界面（与左右滑动等价）；**群头像点击语义见 R-G4**。
- R-G2 默认落在**群聊主界面（聊天）**：标准聊天软件界面（消息列表 + 底部输入框），复用现有聊天能力。
- R-G3 群聊场景内**左右滑动**切换该群自己的五个子界面：**聊天、直播、语音、帖子、桌游**（顺序：语音 | 直播 | 聊天 | 帖子 | 桌游，聊天居中为默认）。
- R-G4 **群头像的两级点击语义**（关键）：
  - 当当前界面**不是群聊主界面**（在直播/语音/帖子/桌游任一子界面）时，点击顶部群头像 → **回到群聊主界面（聊天）**；
  - 当当前界面**已经是群聊主界面**时，点击顶部群头像 → **进入群信息界面**（§3.9）；
  - 群信息界面返回后回到群聊主界面。
- R-G5 **底部输入框显隐规则**（精确）：
  - **群聊主界面（聊天）**：输入框**正常显示**（消息输入）；
  - **群聊直播界面**：输入框**正常显示**（弹幕输入，半透明浮于视频底）；
  - **群聊帖子界面**：输入框**正常显示**（即发帖框，展开为多行编辑器）；
  - **群聊语音界面**：输入框**缩下去（隐藏）**——此界面是语音房卡片列表，点卡片进房间；
  - **群聊桌游界面**：输入框**缩下去（隐藏）**——此界面是桌游室卡片列表，点卡片进房间。
- R-G6 **返回主页**：在群聊场景（任意子界面）将**顶部导航条向下滑动**（下拉手势），整个群聊场景容器退出，回到主页；底部导航条复位到底部、"主页"字样复原。
- R-G7 群聊**直播界面**：不是房间卡片列表，而是**直接进入该群的直播间**；**上下滑动**切换该群内的其他直播间（范围 = 仅该群）。若群内无直播，显示空态 + 创建引导。
- R-G8 群聊**语音/桌游界面**：显示该群的语音房 / 桌游室**卡片列表**，点击卡片进入对应房间。

### 3.4 一级 tab 聚合界面（语音/直播/帖子/桌游）

一级 tab 与群内子界面的关键差异：**聚合范围 = 公开 + 好友 + 已加入群聊** 的房间/内容；且**进入方式与动画不同**（见各条）。

**直播 tab**：
- R-L1 显示**直播间卡片网格布局**：公开直播间 + 好友直播间 + 已加入群的直播间（卡片：封面、标题、主播、来源标识）。
- R-L2 **进入直播间动画（与进群动画方向相反）**：点击卡片 → 底部导航栏**向下滑走**（滑出视口底部）并且**输入框向上滑入**（弹幕输入）——注意：进直播间是"底栏向下滑走"，进群是"底栏向上移到顶部"，两种动画方向不同，不可混用。
- R-L3 直播间内**上下滑动**切换其他直播间——范围 = **全部可见直播间**（公开 + 好友 + 已加入群），与群聊直播界面（仅该群）不同。
- R-L4 左上角**返回键**退出直播间，底栏滑回复位，回到直播 tab 网格。

**语音 tab**：
- R-V1 显示**语音房卡片列表/网格**：公开 + 好友 + 已加入群的语音房（房间名、房主、在麦人数、成员头像堆叠、来源标识）。
- R-V2 点击进入语音房：可**上麦连麦**；**下方弹出输入框**，可在语音房内打字（房间文字消息）；左上角返回键退出回到语音 tab。
- R-V3 返回后底栏复位。

**帖子 tab**：
- R-P1 显示**帖子列表**（单列信息流）：公开 + 好友 + 已加入群的帖子。
- R-P2 发帖入口为**右下角 FAB 加号**（关键差异：一级帖子 tab 用 FAB 发帖，而**群聊帖子界面用底部输入框发帖**，两条路径不同）。
- R-P3 点击帖子进入**帖子详情**：**底部导航栏切换为输入框**（底栏位置被评论输入框替换），可看帖、发评论；左上角返回键返回，底栏复位。
- R-P4 帖子详情交互：评论列表（头像+昵称+时间+内容，支持回复）、发评论、收藏（切换态即时反馈）、删除（仅作者，二次确认）、正文超 3 行折叠"展开/收起"、图片可点击查看大图。

**桌游 tab**：
- R-B1 显示**桌游室卡片列表**：公开 + 好友 + 已加入群的游戏室。桌游玩法本体后续实现，本期完成房间框架（创建/列表/进入占位界面）。

### 3.5 FAB 加号弹窗（随场景切换）

| 当前所在 | FAB 动作 |
|---|---|
| 主页 | 创建群聊 |
| 语音 tab | 创建语音房 |
| 直播 tab | 创建直播间 |
| 帖子 tab | 发帖 |
| 桌游 tab | 创建桌游室 |
| 群聊场景内 | 跟随当前子界面（语音→群内语音房、直播→群内开播、帖子→群内发帖、桌游→群内桌游室；聊天子界面 FAB 隐藏） |

- R-F1 此处创建**默认创建公开的**语音房、直播间、帖子、游戏室；创建表单中可见性选择可后置（见 §6 后续迭代）。
- R-F2 创建的内容归属于当前场景上下文：在一级 tab 创建 = 个人/公开维度；在群聊场景创建 = 归属该群。
- R-F3 创建表单字段（本期最小集）：
  - 创建群聊：群名（必填）、群头像（可选，媒体上传）；
  - 创建语音房：房间名（必填）；
  - 创建直播间：直播间标题（必填）；
  - 发帖：正文（必填）、图片（可选，≤9 张）；
  - 创建桌游室：房间名（必填）。
  - 提交中按钮禁用防重复；失败展示错误并保留已填内容。

### 3.6 消息界面

- R-M1 从左下角消息入口进入，**底部导航切换为两个选项卡：私信、好友列表**。
- R-M2 **私信**：私聊会话列表（复用现有会话列表能力，仅保留 private 会话）。
- R-M3 **好友列表**：我的好友 + **好友申请**（待处理入站申请）+ **群申请/邀请**（我收到的入群邀请、我作为群 owner/admin 收到的待审批入群申请）。
- R-M4 左上角/手势返回主页；消息入口红点 = 私信未读 + 待处理申请数聚合。
- R-M5 好友列表操作：点击好友 → 发起私聊 / 查看资料；删除好友需二次确认；申请条目含 [同意] [拒绝]（处理后灰显结果）。

### 3.7 个人界面

- R-U1 点击主页头像进入个人界面，包含：
  - **修改个人信息**：昵称、头像、签名、在线状态（复用现有 profile 能力）；
  - **查看发帖**：我发布的帖子列表；
  - **直播间**：我创建/管理的直播间；
  - **正在玩的桌游**：我当前在局的桌游室。
- R-U2 左上角返回。
- R-U3 **收藏页**（"更多 → 收藏"）：本期展示我的帖子收藏列表（含取消收藏），直播间/语音房/桌游室/群收藏类型后端预留、界面占位。

### 3.8 全局搜索

- R-S1 点击顶栏搜索框进入搜索界面，支持搜索**全部对象类型**：直播间、桌游房间、用户、帖子、群。
- R-S2 结果**分组展示**（按对象类型分区），点击结果跳转对应界面（用户→用户资料卡/发起私聊；群→群信息/申请加入；直播间→进入观看；帖子→帖子详情；桌游室→房间详情）。
- R-S3 仅展示**对我可见**的结果（公开 + 好友 + 我所在群）。
- R-S4 **用户资料卡**（搜索结果/好友/成员点击头像弹出）：头像、昵称、签名、在线状态、好友关系（已是好友/可加好友/待验证）；"加好友"按钮发起申请（可带验证消息）；"发消息"按钮进入私聊。

### 3.9 群信息界面（进入语义见 R-G4）

- R-G9 群信息界面内容（与当前用户角色相关）：
  - 群资料：群头像、群名、群公告、创建时间；
  - 成员列表：头像+昵称+角色标签（owner/admin/member）；
  - owner/admin：查看**入群申请**（待处理列表，同意/拒绝）、编辑群资料/公告、移除成员、转让群主、解散群（均需二次确认）；
  - 普通成员：退出群（二次确认）、邀请好友入口（搜索用户 → 邀请）；
  - 返回：左上角返回键 → 回到群聊主界面。

## 4. 宽屏（桌面 Web）需求

宽屏是**一等形态**，不是窄屏的放大版。宽屏采用 **"顶部全局导航 + Discord 式左侧栏"** 的混合结构：顶栏保留（承载一级模块切换），**"主页"本身就是 Discord 式三列界面**（服务器栏 + 频道侧栏 + 内容区），不是群卡片网格——**群卡片/列表网格是窄屏专属形态**，宽屏点 TopNav"主页"直接进入最近访问群（无历史则第一个群）的聊天场景。

```
┌──────────────────────────────────────────────────────────┐
│ TopNav: 头像 主页 语音 直播 帖子 桌游 │ 消息 搜索 更多       │  ← 全局一级导航，常驻
├──────┬────────────┬────────────────────────────────────┤
│ 服务器│  频道侧栏    │  内容区顶栏（场景标题）                │
│  栏   │  聊天       │  内容区                             │
│ (群)  │  语音       │                                     │
│      │  直播       │                                     │
│ 底部 │  帖子       │                                     │
│ 用户栏│  桌游       │                                     │
└──────┴────────────┴────────────────────────────────────┘
   ↑ "主页"（即群聊场景）恒有这两列；语音/直播/帖子/桌游 tab 无左栏
```

- R-W1 **顶部导航栏 TopNav**（高 64px，常驻）：**头像（个人界面）、主页、语音、直播、帖子、桌游、消息、搜索框、更多（三）**。当前模块文字主色 + 底部 2px 指示条。它负责跨一级模块切换，与左侧栏不重复——左侧栏只管"当前群内部的场景"。
- R-W2 **主页 = Discord 式三列群聊界面**（宽屏的默认落点与"家"）：
  - **服务器栏**（TopNav 下方最左，72px，常驻）：纵向排列我的群头像（带未读/麦克风/直播/桌游角标），点击切换当前群；底部为用户卡片区（头像+状态，进个人界面）；
  - **频道侧栏**（240–280px）：顶部当前群名称（点击进群信息），下方固定五项群内子场景 **聊天/语音/直播/帖子/桌游**（带在麦人数、LIVE 徽标、未读数等状态标识），点击切换右侧内容区——这是窄屏"群内滑动切子场景"在宽屏的形态；
  - **内容区**：当前场景内容 + 底部内嵌输入框（聊天/直播/帖子/语音房有，桌游无）；
  - 窄屏的群卡片网格主页、进群动画（底栏上移）、群头像两级点击、下拉回主页在宽屏**均不存在**。
- R-W3 **语音/直播/帖子/桌游 tab**（跨群聚合视图）：无左侧栏，内容区铺满 TopNav 下方——直播网格 3–4 列、帖子单列 max-width 680px 居中、桌游 4 列、语音卡片列表。从这些 tab 进入的房间界面同样无左栏、顶栏保留，左上角返回键回到对应 tab。
- R-W4 **需要输入框的页面正常显示输入框**（群聊聊天、直播间弹幕、帖子详情评论、语音房文字），输入框为内容区内嵌底排，不遮挡内容。
- R-W5 **FAB 加号**照常放右下角（`right:32px; bottom:32px`），动作随当前场景切换（一级 tab→对应公开创建；群聊场景→该群对应创建），行为与窄屏一致。
- R-W6 **直播观看**：无论群内直播场景还是聚合 tab 进入，宽屏直播间均为视频主区 + 弹幕侧列 360px；切换直播间用视频两侧按钮 + 键盘 ↑↓，不用上下滑。
- R-W7 **消息页**：双栏——左 300px（私信/好友列表 选项卡 + 列表），右为选中会话聊天面板或好友/申请详情；未选中右侧空态引导。
- R-W8 **个人界面**：两列——左资料卡（头像/昵称/签名/状态/编辑），右三分区（我的发帖/我的直播间/正在玩的桌游）纵向排列。
- R-W9 **搜索**：内联在 TopNav，输入即出下拉分组结果面板（不打断当前页）；回车或"查看全部"进独立结果页。
- R-W10 **宽屏无窄屏手势**，等效控件全集：

  | 窄屏手势/操作 | 宽屏等效 |
  |---|---|
  | 左右滑切五 tab | TopNav 点击 |
  | 群内左右滑切子场景 | 频道侧栏点击（聊天/语音/直播/帖子/桌游） |
  | 进群动画（底栏上移） | 不存在（主页即三列群聊界面） |
  | 群头像两级点击 | 不存在（频道侧栏顶部群名 → 群信息；场景切换走频道侧栏） |
  | 下拉回主页 | 不存在（宽屏本就在主页；切模块用 TopNav） |
  | 直播间上下滑切换 | 视频两侧切换按钮 + 键盘 ↑↓ |

## 5. 响应式断点

- R-R1 沿用 design.md §9 断点体系：**480 / 768 / 1024 / 1440**；≤768px 走窄屏形态，>768px 走宽屏形态；验证视口 375 / 768 / 1024 / 1440。
- R-R2 同一 URL 在两种形态间随视口切换，状态尽量保留（群场景：窄屏的"群内子界面"映射为宽屏频道侧栏的对应项）。
- R-R3 窄屏以移动优先编写，宽屏用 `min-width: 769px` 增强；两形态共享组件与设计 token，仅布局容器不同。
- R-R4 ≤768px 时辉光阴影强度降 30%（沿用 design.md §9 的移动端省电约定）。

## 6. 非目标与后续迭代

- 不做移动端 App（本期 Web 响应式覆盖窄屏场景）。
- 桌游玩法本体不做，仅房间框架。
- 扫一扫、个性化、收藏的具体功能细节后续定义（本期完成入口与收藏的后端基础）。
- 房间/帖子可见性的细粒度编辑（公开/好友/群成员切换）本期默认公开，编辑能力后置。
- 群公告强提醒、直播间连麦等列为后续。

## 7. 验收要点（摘要）

1. 窄屏：五 tab 可点击+可滑动切换；主页双布局切换并持久化；卡片轮播正常播放群内动态。
2. **进群动画方向正确**：底栏整体上移到视口顶部（非滑出），"主页"字样变群头像；群头像两级点击语义正确（非聊天子界面→回聊天；聊天界面→群信息）。
3. **进直播间动画方向正确**：底栏向下滑走 + 输入框向上滑入（与进群动画相反）；帖子详情底栏切换为输入框。
4. 输入框显隐规则符合 R-G5；群内直播上下滑切换范围=仅该群；一级直播 tab 上下滑切换范围=公开+好友+已加入群。
5. FAB 在八个场景动作正确；创建默认公开且归属正确。
6. 消息界面双选项卡数据正确；好友/群申请可处理。
7. 搜索五类对象均有结果分组且可见性过滤生效。
8. 宽屏：TopNav 一级导航齐全；点"主页"直接进入 Discord 式三列群聊界面（无群卡片网格中间层）；直播间弹幕侧列与键盘切换正常；输入框与 FAB 正常。
9. 四种验证视口（375/768/1024/1440）布局切换无内容丢失；全部界面通过 design.md §10 可访问性自查（对比度、focus ring、≥40px 触达目标）。
