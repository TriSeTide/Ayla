**硬约束（继承 AGENTS.md + 开发文档）**：
- **主体性铁律（AGENTS.md §4.1 / FR-19）**：爱莉直播是"应用内普通 User 开直播 + 订阅阶段三 livestream 状态投影"，应用侧**绝不生成、改写爱莉的直播内容/第一人称叙事**；直播画面/弹幕只做呈现与路由。
- **媒体安全（继承 M4-3）**：直播不落媒体对象存储（视频流在 SRS，不转码不落盘）；`stream_key` 是推流握手指纹，**必须随机唯一、序列化不可回显**（只给 owner 可见；descriptor 不给他人）。
- **状态真实性（AGENTS.md §8）**：应用侧 `status` 是乐观标记；**"是否在播"以 SRS HTTP API 实时查询为准**（`/api/v1/streams` 匹配 app+stream）。禁止把应用侧标记伪装成真实直播状态；SRS 查询失败要区分 `degraded/failed`，不能当"未在播"。
- **工程硬约束**：弹幕经 WebSocket 广播（channels group），落库与广播分离（复用 M4-5 模式）；Django 事件循环不做阻塞 I/O（SRS HTTP 查询走同步线程/短超时）。
- 每次改动要有与风险相称的契约测试（频道生命周期/状态判定/弹幕广播/越权）。
- 只写 `apps/live/` 相关代码与必要配置接线；不动 accounts/chat/media/emoji/voice/elysia_bridge 已有模型与接口（除非公共契约确有缺陷，先说明再动）。

## 1. 目标（M4-6 验收定义）

完成**应用内直播闭环**：真人/授权主播开播（OBS/浏览器推流到 SRS）→ 应用创建直播频道、生成推流/播放地址 → SRS 活跃流状态查询 → 直播间弹幕（WebSocket 实时广播）→ 下播状态收敛。

- **SRS 集成**：Docker Compose 编排 `ossrs/srs:5`；RTMP 推流（1935）、HTTP-FLV/HLS 播放（8080）、HTTP API 状态查询（1985）、WebRTC（可选，1985+8000/udp）。
- **直播频道**：创建频道生成安全随机 `stream_key`；RTMP 推流地址 `rtmp://<host>:1935/live/{stream_key}`、播放地址（HLS `.m3u8` / HTTP-FLV `.flv`）；`status`（idle/live/ended）乐观标记 + SRS 实时判定。
- **弹幕**：发送落库 + channels group 实时广播（`live_{channel_id}`）；新进房间可拉最近 N 条历史。
- **爱莉直播**：订阅阶段三 `/livestream/*` 状态的**通道预留**（本期不验收，见 §6）。
- **契约测试**：频道 CRUD/越权、stream_key 唯一与不回显、SRS 状态判定（fake 注入）、弹幕落库+广播、WS 收弹幕。

**不包含（本里程碑边界）**：
- **视频转码/录制**：SRS 不做转码（OBS 推流侧编码），不接 FFmpeg 转码/录制落盘。
- **礼物系统**（FR-18 可选）：本期不做，接口不预留。
- **前端直播间/播放器**（M5-4）：本期只做后端 API + WS + 契约测试；前端拉流播放、弹幕 UI、推流指引归 M5-4。
- **爱莉直播真实对接**（FR-19）：依赖阶段三 `/livestream/*` 接口形态 + Elysium 直播意识接入（用户当前不负责 Elysium 侧）——**未决点**，本期只留订阅通道（见 §6），不验收。
- **WebRTC 低延迟播放**（<500ms）：SRS 支持，但本期首验 HLS/HTTP-FLV（5-15s 可接受），WebRTC 标注可选。

## 4. SRS 集成（apps/live/srs.py）

### 4.1 SRS 5 能力与地址格式（首期只用这些）

| 用途 | 协议 | 地址格式 | 端口 |
|---|---|---|---|

## 5. 应用内 REST 与 WS（挂 `/api/v1/live/`）

### 5.1 直播频道

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/api/v1/live/channels/` | 创建频道 `{title}` → `{id, title, stream_key, rtmp_url, hls_url, flv_url, status}`（**stream_key 仅创建响应回显一次**，后续详情不返回 stream_key 给非 owner） | 登录 |
| GET | `/api/v1/live/channels/` | 频道列表（含 status；可 `?only_live=1` 过滤） | 登录 |
| GET | `/api/v1/live/channels/{id}/` | 频道详情：owner 可见 stream_key + 推流地址；他人可见播放地址 + 状态 | 登录 |
| POST | `/api/v1/live/channels/{id}:start/` | 开播（status→live、started_at=now；**不校验 SRS 真实流**，由 /status 判定） | 频道 owner |
| POST | `/api/v1/live/channels/{id}:stop/` | 下播（status→ended、ended_at=now） | 频道 owner |
| GET | `/api/v1/live/channels/{id}/status/` | **SRS 实时判定**：在播 / 未在播 / degraded（srs 不可用） | 登录 |
| DELETE | `/api/v1/live/channels/{id}/` | 删除频道（直播中禁止删除，先 :stop） | 频道 owner |

**频道 descriptor（LiveChannelSerializer）**：

```json
{
  "id": 1, "title": "爱莉的午后", "status": "live",
  "owner_id": "...", "is_owner": true,
  "stream_key": "a1b2...",            // 仅 owner 可见；他人为 null
  "rtmp_url": "rtmp://127.0.0.1:1935/live/a1b2...",   // 仅 owner
  "hls_url": "http://127.0.0.1:8080/live/a1b2....m3u8", // 全员
  "flv_url": "http://127.0.0.1:8080/live/a1b2....flv",  // 全员
  "started_at": "...", "ended_at": null, "created_at": "..."
}
```

> **stream_key 最小权限（工程硬约束）**：创建响应回显一次供复制进 OBS；此后仅 owner 的详情可见；非 owner 一律 null。禁止把推流指纹暴露给观众。

### 5.2 弹幕

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/api/v1/live/channels/{id}/danmaku/` | 发弹幕 `{content}` → 落库 + 广播 `live_{id}` group | 登录 |
| GET | `/api/v1/live/channels/{id}/danmaku/?limit=` | 最近弹幕历史（默认 50，上限 200） | 登录 |
| WS | `/ws/live/{channel_id}/` | 弹幕实时帧 `{"type":"danmaku","id":..,"sender":{..},"content":"..","created_at":".."}` | JWT token 认证 |

**弹幕广播实现（复用 M4-5 `voice.state` 模式）**：
- 落库与广播分离：视图内 `database_sync_to_async` 落库 → `async_to_sync(group_send)` 广播（注意 M4-5 教训：不要在事件循环线程里同步调 group_send；按 `_group_send_async` 模式拆）。
- 广播帧带 `sender` 序列化（昵称/头像），content 原样（应用不代判内容）。
- WS 连接用 JWT 认证（复用 accounts presence WS 的 token 解析）；channel 不存在/无权限 → 关闭连接。
- **在线人数**（FR-18 可选）：本期不做精确计数（WS 连接数可用 channels group 统计，标注可选）。

## 6. 爱莉直播（主体性边界 + 通道预留）

### 6.1 主体性铁律（继承 AGENTS.md §4.1）

- 爱莉在应用内是**一个真实 User**（M4-4 `elysia_profile` 绑定）；她开播 = `owner=爱莉user` 的普通 LiveChannel，画面/弹幕在应用内就是普通直播间数据。
- 应用侧**绝不生成、改写爱莉的直播内容、第一人称叙事或弹幕**；只做呈现与路由。导演/OBS 舞台/同一意识是 Elysium 直播系统的事，应用侧不实现。

### 6.2 本期能力（应用内直播链）

- 任意登录用户（含爱莉 user，通过 M4-4 通道）都可创建频道、OBS/ffmpeg 推流、弹幕互动。**契约测试必须覆盖**（频道 CRUD、弹幕广播、越权）。

### 6.3 未决点（爱莉直播真实对接，必须显式标注，不阻塞本期）
