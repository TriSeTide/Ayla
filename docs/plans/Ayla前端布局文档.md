# Ayla 前端布局文档（聚合主页与多端布局）

> 布局规格文档。**窄屏（≤768px）与宽屏（>768px）是一等公民的两种形态**：窄屏走"底部五 tab + 手势"的移动式信息架构，宽屏走"顶部常驻 TopNav + 群聊场景 Discord 式左侧栏"的桌面信息架构，两者共享组件与设计 token，仅容器不同。
> 配套文档：`Ayla聚合主页与多端布局需求文档.md`、`Ayla聚合主页与多端布局开发文档.md`。
> **视觉唯一事实源：`Ayla/docs/design.md`（千禧冰樱 / Y2K Frost）**。本文所有尺寸/颜色/动效从其 token 与刻度推导；本文不定义新颜色，组件内禁止裸 hex。动手前必读项目级 skill `.workbuddy/skills/ayla-frontend-design`。

## 1. 断点与全局框架

断点沿用 design.md §9：**480 / 768 / 1024 / 1440**；验证视口 375 / 768 / 1024 / 1440。

| 断点 | 形态 | 导航 |
|---|---|---|
| ≤768px | 窄屏 | 底部五 tab + 左下消息 FAB + 右下创建 FAB |
| >768px | 宽屏 | 顶部常驻导航栏 + 右下创建 FAB（消息在顶栏） |

- 全局外壳 `AppShell` 按 `useMediaQuery('(max-width: 768px)')` 切换两种导航形态。
- **窄屏内细分**：≤480px 群卡片 2 列保持但 padding/gap 收紧（8px/8px）；375 验证视口保持 2 列（封面可收紧为 3:2）；<360px 群卡片改 1 列；消息气泡 max-width 84%。
- 全局背景：固定 `--bg-aurora` 极光渐变（design.md §6，z 最低不动），内容在其上滚动。
- z-index 分层（自下而上）：背景 → 内容 0 → 底部输入框 40 → 底栏/顶栏 50 → FAB 60 → 弹层/抽屉 80 → toast 100。弹层玻璃底用 `--glass-bg-strong`（模态需更高遮挡时），背景压暗 `rgba(70,91,146,0.25)`。
- 窄屏底栏适配 `env(safe-area-inset-bottom)`。
- ≤768px 辉光阴影强度降 30%（design.md §9 移动端省电约定）。
- **反馈与加载**：
  - 骨架屏：所有 >300ms 的异步加载用玻璃质感骨架块（design.md §7），禁止白屏；
  - Toast：全局轻提示（成功/失败/信息），玻璃底 + 圆角 12px，底部居中（窄屏避让输入框）/ 右上角（宽屏），2.5s 自动消失，可关闭。

## 2. 窄屏布局

### 2.1 一级界面骨架（五个 tab 共用）

```
┌──────────────────────────┐
│ TopBar          h=56px   │  主页：头像 | 搜索框 | 三
├──────────────────────────┤
│                          │
│   Content (scroll)       │  padding-bottom 避让底栏+FAB
│                          │
├──────────────────────────┤
│ (MsgFAB)         (FAB)   │  悬浮层，不占位
│ BottomTabs      h=64px   │  语音 直播 [主页] 帖子 桌游
└──────────────────────────┘
```

- **TopBar**：高 56px，玻璃底（`--glass-bg` + blur 18px，design.md §4 Nav）。主页三件套：左头像 36px 圆形（带在线光环）、中搜索框（胶囊，底 `--surface`、1px `--ice-300` 描边、focus 转 `--glow-500` + 辉光）、右"三"按钮 40px（触达目标 ≥40px）。
- **BottomTabs**：高 64px，玻璃底五等分。**主页 tab 居中选中态凸起**（圆形背板上浮 8px + `--glow-shadow`）；其余 tab 线性 SVG 图标（Lucide 风格 2px 描边，禁止 emoji 图标）+ 11px Fredoka 文字。未读小红点为 `--pink-500` 实底白字徽标。
- **MessageFAB**：左下 56px 圆形玻璃底，底距 = 底栏高 + 12px；聚合未读红点。
- **CreateFAB**：右下 56px 圆形，主 CTA 样式（`--indigo-700` 实底白加号，hover/按下附辉光）；点击弹底部动作面板（`--glass-bg-strong` 玻璃 + 圆角 24px 上沿）。

### 2.2 主页（群聊集合）

**卡片布局**（默认）：

```
内容区 grid: 2 列, gap 12px, padding 12px
卡片（实心卡片底 --surface + 圆角 16px + 极浅投影）:
  ┌────────────┐
  │ ┌────────┐ │  封面区 4:3，轮播（群内动态封面，3s 自动切换，圆角 12px 内嵌 8px）
  │ │ 轮播图 │●│  右上角：状态角标列（未读 > 直播 > 语音 > 桌游，纵向叠放）
  │ └────────┘ │
  │ [头像] 群名 │  底部行：群头像 24px（带光环）+ 群名一行省略（Nunito 700 15px）
  └────────────┘
```

- 分页：滚到底加载更多 + `· · ·` 指示。
- **列表布局**：行高 64px；左群头像 44px（叠加角标），中群名 + 新消息预览（13px `--text-secondary`，一行省略），右未读徽标。视觉对齐 QQ 会话列表，玻璃底整面。
- **布局开关**：TopBar 下方或"三"菜单内；选择存 localStorage + 用户设置。
- **状态角标**：16px 线性 SVG 图标 + `--pink-500`/`--glow-500` 底圆；未读为 `--pink-500` 红底白字数字徽标（99+ 截断）；最多 3 个，优先级 未读 > 直播 > 语音 > 桌游。
- 轮播属装饰性循环动画的**例外**：进视口才启动、离开暂停（IntersectionObserver），`prefers-reduced-motion` 降级为首帧静态。
- **滚动行为**：主页滚动为普通列表滚动；进入群聊场景容器时主页滚动位置保留（返回时原位恢复，R-N3）。

### 2.3 群聊场景容器（窄屏 GroupPage）——底栏上移到顶部

**核心布局变化**：进入群后，**BottomTabs 整体从底部上移到视口顶部**，形成顶部导航条；原"主页"槽位内容变为群头像；底部让位给输入框。

```
┌──────────────────────────┐
│ TopTabs'       h=64px    │  语音 直播 [群头像] 帖子 桌游   ← 底栏上移后的形态
│ 子界面指示 (5 小圆点)      │  仅非聊天子界面显示
├──────────────────────────┤
│  子界面（横向滑动容器）     │  voice | live | chat | posts | games
│                          │  聊天居中默认；直播为沉浸式直播间
├──────────────────────────┤
│ InputBar        h=56px   │  仅 chat / live / posts 显示
└──────────────────────────┘
```

**进场动画（点击主页群卡片，动画方向 = 底栏上移到顶部）**：
1. BottomTabs 容器 `transform: translateY(0 → -100vh + 64px)`（从底部位置整体上移到视口顶部），250ms ease-out；同时中央"主页"文本交叉淡化为群头像（槽位宽 48→64px 弹性过渡）；
2. 输入框 `translateY(100%→0)` 250ms ease-out 滑入（延迟 100ms）；
3. 内容淡入 200ms。

**退出（回主页）**：顶部导航条区域下拉手势（仅子界面滚到顶时启用），跟手位移 + 松手超 80px 触发反向动画（TopTabs 下移回底部、"主页"字样复原）+ `navigate(/home)`。

**群头像点击语义（两级，视觉与交互）**：
- 当前在**直播/语音/帖子/桌游**任一子界面 → 点击群头像 = 切回**聊天子界面**（`chat` 居中）；
- 当前在**聊天子界面** → 点击群头像 = 进入**群信息界面**（GroupInfo 覆盖层，返回回聊天）。
- 实现提示：群头像点击行为由"当前子界面是否为 chat"驱动，单一 handler 内分支，避免两层导航状态打架。

**子界面切换**：横向滑动手势（方向锁：垂直位移占优时让位滚动）；顺序 `语音 | 直播 | 聊天 | 帖子 | 桌游`，聊天居中默认。顶栏下 5 个小圆点指示当前位置（非聊天子界面才显示，避免聊天界面拥挤）。

**输入框显隐**（R-G5 精确规则）：

| 子界面 | 输入框 | 说明 |
|---|---|---|
| 聊天 | 显示 | 现有 MessageInput 全功能 |
| 直播 | 显示 | 弹幕输入（半透明浮于视频底） |
| 帖子 | 显示 | 输入框即发帖框（展开多行编辑器） |
| 语音 | **隐藏** | 子界面 = 语音房卡片列表 |
| 桌游 | **隐藏** | 子界面 = 桌游室卡片列表 |

### 2.4 群内直播子界面（沉浸式，窄屏）

- **全屏视频**：进入即播该群第一个直播间，无卡片列表。
- **上下滑切换**：垂直手势在**群内直播间列表**内 prev/next（范围 = 仅该群）；跟手 + 上下一张 20% 预览露出，松手过半切换；弹幕输入框保持。
- 覆盖层：顶部主播信息行（玻璃底）、底部弹幕输入框（`--glass-bg-strong` 半透明）；无直播 → 空态（插画位 + "发起直播"主 CTA）。

### 2.5 一级 tab 界面（窄屏）——进入动画方向与进群相反

**直播 tab**：卡片 2 列网格；卡片 = 封面 16:9 + LIVE 徽标（`--pink-500` 底白字胶囊）+ 标题 + 主播 + 来源标识。
- **进直播间动画（底栏向下滑走 + 输入框滑入）**：点击卡片 → BottomTabs `translateY(0→100%)` 滑出视口底部（200ms ease-in）＋ 弹幕输入框 `translateY(100%→0)` 滑入（250ms ease-out，延迟 100ms）——**与进群动画（底栏上移）方向相反，不可混用**。
- **上下滑切换**：范围 = 全部可见直播间（公开 + 好友 + 已加入群），与群内直播（仅该群）不同。
- 左上角返回键（40px 圆形玻璃容器 + 箭头）→ 底栏复位回底部，回到网格。

**语音 tab**：卡片单列；房间名 + 房主 + 在麦人数 + 成员头像堆叠（≤5 个重叠圆形，带光环）+ 来源标识。点击 → 语音房整页：**底栏同样下滑走 + 输入框弹出**（房内打字）；成员网格（头像+麦克风状态）、底部控制排（静音/扬声器/上麦/离开，48px 圆形玻璃钮，离开为 `--destructive`）；左上角返回。

**帖子 tab**：单列信息流；卡片 = 作者头像(光环)+昵称+时间（时间戳 Space Grotesk 12px）、正文（超 3 行折叠"展开"）、图片九宫格、底排（评论数/收藏）。**FAB 发帖**（区别于群内帖子界面的输入框发帖）。点击 → 帖子详情整页：**底栏位置切换为评论输入框**（不是滑走，是原位替换）；左上角返回后底栏恢复。

**桌游 tab**：房间卡片 2 列：封面占位 + 房间名 + 状态 tag（等待中/对局中，`--sakura-300` 底 `--grape-700` 字胶囊）+ 人数。点击 → 房间占位界面；左上角返回。

### 2.6 消息界面（窄屏）

```
┌──────────────────────────┐
│ ← 消息                   │
│ [ 私信 | 好友列表 ]       │  分段选项卡（胶囊选中底 rgba(157,191,230,0.35)）
├──────────────────────────┤
│  私信：私聊会话列表         │
│  好友：                   │
│   ▸ 好友申请 (n)          │  待处理置顶
│   ▸ 群申请/邀请 (n)       │
│   ─────────────          │
│   好友列表（字母排序）      │
└──────────────────────────┘
```

- 本期采用**页内分段选项卡**（底栏保留）。
- 申请条目：头像 + 名称 + 验证消息 + [同意] [拒绝]（同意 = Primary 胶囊、拒绝 = Ghost，design.md §4 Buttons）；处理后灰显结果。

### 2.7 个人 / 搜索 / 更多（窄屏）

- **个人界面**：顶部大卡（头像 72px 带光环 + 昵称 Fredoka 28px + 签名 + 状态 chip + 编辑钮），下分区列表：我的发帖 / 我的直播间 / 正在玩的桌游，各分区横向卡片条（超出横滑）+ "查看全部"。
- **搜索界面**：TopBar 变搜索输入态（自动聚焦 + 左返回）；历史搜索（可清空）；结果分组：用户/群聊/直播间/帖子/桌游室，组头 + ≤3 条 + "查看更多"。
- **更多菜单**："三"→ 右上浮层（宽 200px，圆角 16px，`--glass-bg-strong`）：个性化 / 扫一扫 / 收藏，线性图标 + 文字行。

## 3. 宽屏布局（一等形态）

宽屏不是窄屏拉伸。结构 = **顶部全局 TopNav + "主页"即 Discord 式三列群聊界面**。TopNav 管跨一级模块切换，左侧栏管当前群内部场景，两者不重复。**宽屏没有群卡片网格主页**——点 TopNav"主页"直接进入最近访问群（无历史则第一个群）的聊天场景。

### 3.1 TopNav 与聚合 tab 页面

```
┌────────────────────────────────────────────────────────┐
│ TopNav h=64px（常驻，玻璃底）                             │
│ [头像] 主页 语音 直播 帖子 桌游 │ 消息● │ [搜索框] │ 三  │
├────────────────────────────────────────────────────────┤
│  Content  max-width 1200px 居中（design.md §5 限宽）     │
│  （语音/直播/帖子/桌游 tab：无左侧栏，内容铺满）             │
│                                                   (FAB)│
└────────────────────────────────────────────────────────┘
```

- **TopNav**（高 64px，`--glass-bg` + blur 18px，常驻不滚走）从左到右：头像（40px 带光环，→个人界面）、主页、语音、直播、帖子、桌游、消息（带未读徽标）、搜索框（240px 胶囊）、更多（三）。当前模块：`--text-primary` 文字 + 底部 2px `--glow-500` 指示条。
- **语音/直播/帖子/桌游 tab**（跨群聚合视图）：无左侧栏，内容铺满 TopNav 下方。
- **FAB**：右下固定 `right:32px; bottom:32px`，样式与行为同窄屏（面板改为上方浮层）。
- **输入框**：需要的页面正常渲染为内嵌底排，不遮挡内容。
- 网格列数（仅聚合 tab 与卡片列表场景）：直播 3–4 列、帖子单列 max-width 680px 居中、桌游 4 列；卡片间距 ≥16px、12 列 24px gutter（design.md §5）。

### 3.2 主页 = Discord 式三列群聊界面（宽屏的"家"）

点 TopNav"主页"（或打开 `/group/:id`）即为此形态，**无群卡片网格中间层**：

```
┌──────────────────────────────────────────────────────────┐
│ TopNav（常驻）                                             │
├──────┬──────────────┬───────────────────────────────────┤
│服务器 │ 频道侧栏       │  内容区顶栏（场景标题）               │
│ 栏   │  · 聊天       │  内容区                            │
│ 72px │  · 语音       │  + 内嵌底部输入框                    │
│ 群头像│  · 直播       │                                   │
│ 列表  │  · 帖子       │                                   │
│      │  · 桌游       │                                   │
│ 底部 │ (240-280px)   │                                   │
│ 用户卡│              │                                   │
└──────┴──────────────┴───────────────────────────────────┘
```

- **服务器栏 ServerRail**（72px，整面玻璃）：纵向我的群头像（48px 圆形带光环 + 未读/麦克风/直播/桌游角标），点击切换当前群；底部用户卡片区（头像 40px + 状态，进个人界面）。当前群头像高亮（左侧 3px `--glow-500` 指示条）。
- **频道侧栏 ChannelSidebar**（240–280px，整面玻璃）：顶部当前群名（Fredoka 20px，点击进群信息），下方固定五项群内子场景——**聊天/语音/直播/帖子/桌游**，每项带状态标识（语音在麦人数、直播 LIVE `--pink-500` 徽标、帖子未读数等）；点击切换内容区。选中项 `rgba(157,191,230,0.35)` 胶囊底。
- **内容区**：当前场景内容 + 底部内嵌输入框（聊天/直播/帖子/语音房有，桌游无）。
- 窄屏的群卡片网格主页、进群动画（底栏上移）、群头像两级点击、下拉回主页在宽屏**均不存在**；群信息入口 = 频道侧栏顶部群名。
- **直播观看**（群内直播场景或聚合 tab 进入）：视频主区 + **弹幕侧列 360px**；切换直播间用两侧按钮 + 键盘 ↑↓。

### 3.3 宽屏手势替代全集

| 窄屏手势/操作 | 宽屏等效 |
|---|---|
| 左右滑切五 tab | TopNav 点击 |
| 群内左右滑切子场景 | 频道侧栏点击（聊天/语音/直播/帖子/桌游） |
| 进群动画（底栏上移） | 不存在（主页即三列群聊界面） |
| 群头像两级点击 | 不存在（场景切换走频道侧栏；群信息走侧栏顶部群名） |
| 主页点群卡片进群 | 不存在（服务器栏点群切换） |
| 下拉回主页 | 不存在（宽屏本就在主页；切模块用 TopNav） |
| 直播间上下滑切换 | 视频两侧切换按钮 + 键盘 ↑↓ |

### 3.4 宽屏其他界面

- **消息页**：双栏——左 260px 会话列表侧栏（私信/好友选项卡 + 列表；宽度与主页 ChannelSidebar 一致，宽窄形态共用同一侧栏宽度），右为选中会话聊天面板（私信）或好友/申请详情；未选中右侧空态引导。
- **个人界面**：两列——左资料卡（头像/昵称/签名/状态/编辑），右三个分区（我的发帖/直播间/桌游）纵向排列。
- **搜索**：顶栏内联搜索框，输入即出下拉分组结果面板（不打断当前页）；回车或"查看全部"进独立结果页。
- **直播间（一级 tab 进入）**：视频主区 + 弹幕侧列 360px，弹幕输入框在侧列底部。

## 4. 共享组件规格（两形态复用）

| 组件 | 规格要点 |
|---|---|

## 6. 落地纪律（继承 design.md）

1. 所有样式只用 `tokens.css` 变量，组件内禁止裸 hex；§4 有现成配方就照搬，没有就按 §2/§3/§5 token 与刻度推导，推导不出改 design.md 而不是发明一次性样式。
2. 间距刻度 4/8/12/16/24/32/48；圆角刻度 8/12/16–20/24–28/999。
3. 辉光每屏 ≤3 处，只给爱莉、主 CTA、focus；≤768px 辉光降 30%。
4. 线性 SVG 图标（2px 描边圆角端点），emoji 不作功能图标；爱莉专属气泡/光环不可复用于普通用户。
5. 可访问性（design.md §10）：正文对比度 ≥4.5:1、触达目标 ≥40px、`#F796FF` focus ring 禁止 `outline:none` 无替代、在线状态 = 光环 + 文字双通道、列表与操作键盘可达。
6. 手势统一封装 `useSwipe` hook（方向锁、阈值、取消），五 tab / 子界面 / 直播间三处复用；手势仅窄屏挂载。
7. 窄屏输入框聚焦时底栏随键盘收起（`visualViewport` 监听），输入框贴键盘顶。
8. **动画方向纪律**：进群=底栏上移、进直播间/语音房=底栏下滑走+输入框滑入、帖子详情=底栏原位替换为输入框——三种转场方向在实现中必须各自独立封装（`useEnterGroupAnimation` / `useEnterRoomAnimation` / `usePostDetailTransition`），不得共用同一动画组件导致方向串味。
