# Ayla 前端加载与动画 —— 快速参考

> 立即可验收的功能 + 常见问题排查。

## 立即可验收的功能

1. **帖子详情秒开 + 并行加载**：进 `/posts/:id` 正文与评论同时加载，不再串行等待。
2. **帖子详情结构化骨架 + 入场浮入**：弱网看骨架，正常网看详情卡浮入 + 评论逐条浮现。
3. **语音房入场动画统一**：点进语音房，成员面板与聊天卡浮入（不再闪现）。
4. **评论实时同步**：两浏览器打开同一公开帖，一端发/删评论，另一端实时更新（需后端重启生效）。
5. **登录预加载帖子**：刷新进 App，登录后后台已拉好帖子列表，进帖子页秒开。
6. **路由懒加载**：首屏只加载当前页 chunk，其余按需加载。

## 常见问题排查

| 现象 | 排查 |
|---|---|
| 帖子详情评论不实时 | ① 后端是否已重启（consumer handler + broadcast 生效前提）② 帖子是否为公开/群帖（friends 帖仅推给帖主）③ WS 是否 online |
| `.reveal` 内容不显示 | 确认 JS 已挂载（hook 第一步 rAF 后 `.is-in`）；reduced-motion 应直接不隐藏 |
| 评论列表无 stagger | 确认 `CommentList` 传入 `revealItems`（详情页已传）；`prefers-reduced-motion` 下关闭位移属预期 |
| 首屏 chunk 过大 | 检查是否有页面 import 了 livekit/hls（`LiveRoomBody` 因 livekit 较大属正常，仅进直播间才加载） |

## 设计 token 提醒

- 所有颜色用 `tokens.css` 变量，禁止裸 hex；本次只改动样式文件中的动画/骨架类，未新增颜色。
- 动画遵循 design.md §7：150–300ms ease-out；`prefers-reduced-motion` 关闭位移保留透明度渐变。
