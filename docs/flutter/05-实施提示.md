## 1. 核心 token 速查（CSS token → Flutter 写法）

> 全部值来自 `Ayla/web/src/styles/tokens.css` 与 design.md §2。Flutter 侧建立 `Tokens` 类（`lib/theme/tokens.dart`），全站引用，**禁止组件内散落裸色值**（对应 web 端禁裸 hex 纪律）。

| 语义 | CSS 值 | Flutter 写法（Color/BoxDecoration） |
|---|---|---|
| 全局背景（极光渐变） | `linear-gradient(160deg, #BDD4E9, #ECF0F2 38%, #FCD8FF)` | `LinearGradient(begin: topLeft, colors: [#BDD4E9, #ECF0F2, #FCD8FF], stops: [0, .38, 1])`（静态底；动态流体背景见坑 2） |
| 正文/主交互 | `#465B92`（indigo-700，对比度 6.4:1） | `Color(0xFF465B92)`——正文、标题、主按钮底、图标 |
| 次要文字 | `#7E95BD`（≥14px 才可用，对比度 ~2.9:1） | 只用于 14px+ 的次要信息；禁用在小号正文 |
| 粉底文字 | `#722E88`（grape-700，粉底对比度 6.6:1） | 爱莉气泡文字、sakura 底上文字 |
| 玻璃卡底 | `rgba(255,250,251,0.55)` | `Color(0x8CFFFAFB)`（0.55 透明度）；弹层用 0.78 |
| 玻璃卡描边 | `1px solid rgba(255,255,255,0.65)` | 边框 `Color(0xA6FFFFFF)` 宽 1 |
| 玻璃卡圆角 | 16px（卡片/侧栏）；12px（按钮/输入/导航项）；20px（弹窗）；24px（抽屉上沿） | `BorderRadius.circular(16/12/20/24)` |
| 玻璃卡阴影 | `0 8px 32px rgba(70,91,146,.2)` + 顶沿内高光 | `BoxShadow(color: Color(0x337A5B92), blurRadius: 32, offset: Offset(0,8))`；hover 升 12/40 |
| 辉光 | `0 0 16px rgba(247,150,255,0.45)` | `BoxShadow(color: Color(0x73F796FF), blurRadius: 16)`——**全屏 ≤3 处**（爱莉/主 CTA/focus） |
| 自己气泡 | `linear-gradient(135deg, #9DBFE6, #BDD4E9)` + indigo 字 | LinearGradient + 圆角 18（右下 6 小角） |
| 爱莉气泡 | `linear-gradient(135deg, #FCD8FF, #F9B0FF)` + grape 字 + 1px `rgba(247,150,255,0.5)` 描边 | 圆角 18（左下 6）——**全应用唯一，不可复用于他人** |
| 他人气泡 | `rgba(255,250,251,0.72)` 玻璃底 + indigo 字 | Color(0xB8FFFAFB) |
| 在线光环 | `conic-gradient(from 210deg, #9DBFE6, #F9B0FF, #F796FF, #9DBFE6)` 2.5px | Flutter 无 conic-gradient：用 `ShaderMask`/CustomPaint 画锥形渐变环，或近似：`SweepGradient`（transform 旋转 -150° 对齐 210deg 起点）；爱莉加 3.2s 呼吸辉光（opacity .5↔.9） |
| 未读徽标 | `#F17EB3`（pink-500）实底白字 | Color(0xFFF17EB3) + 白字 11px |
| 成功/警告/危险 | `#3FA97C` / `#E8A33D` / `#D64D6E` | Color(0xFF…) |
| Focus ring | `2px solid #F796FF` + 2px offset | 自定义 Focus 装饰（`BoxDecoration(border: Border.all(color: glow, width: 2))`） |
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32 / 48 | `Tokens.sp(4..48)`；聊天密度 8/12/16 |
| 字体 | Display `Fredoka`(600/500)、Body `Nunito`(400/600/700)、Utility `Space Grotesk` | pubspec fonts 打包三字体；CJK 走 `fontFamilyFallback`（PingFang SC/Noto Sans SC/Microsoft YaHei）；正文最小 13px |

**配比纪律**：任一屏内粉系（sakura/glow/pink）与蓝系（ice/indigo）必同时出现；辉光全屏 ≤3 处；爱莉专属样式（粉渐变气泡+光环呼吸）禁止复用到普通用户。

## 2. 组件配方速查（直接照抄）

> 参数公式来自 design.md §4 / §12。Flutter 侧建议建 `GlassCard`/`GlassButton`/`GlassInput`/`AvatarHalo` 几个基类统一承载，组件内不再重复写材料。

### 2.1 GlassCard（全站卡面材料）

```
底: Color(0x8CFFFAFB)（0.55 半透暖白）
blur: 18~24px（对应 ImageFilter.blur(18~24) + BackdropFilter；性能策略见坑 1）
描边: 1px Color(0xA6FFFFFF)
圆角: 16px
阴影: 0 8px 32px Color(0x337A5B92)
可交互卡 hover: 上浮 2px + 阴影 12/40 + 300ms（Flutter: AnimatedContainer / Transform.translate）
按下: scale .98（200ms）
```

### 2.2 气泡三态（§4 Chat Bubbles）

| 态 | 底 | 文字 | 圆角 |
|---|---|---|---|
| 自己 | `#9DBFE6→#BDD4E9` 渐变 | `#465B92` | 18px（右下 6） |
| 爱莉 | `#FCD8FF→#F9B0FF` 渐变 | `#722E88` | 18px（左下 6）+ 1px 粉描边 |
| 他人 | `0x72 白` 玻璃 | `#465B92` | 18px |

引用回复：左侧 3px `#9DBFE6` 竖条 + 弱化透明度。到达动画：180ms 从下 8px 浮入淡入（仅新到消息，历史不播）。

### 2.3 在线光环 AvatarHalo（签名元素）

```
环: 2.5px 锥形渐变（#9DBFE6 → #F9B0FF → #F796FF → #9DBFE6）
爱莉: + 8px 辉光呼吸（opacity .5↔.9，3.2s ease-in-out）

### 2.4 按钮三类（§4 Buttons）

| 类 | 配方 |
|---|---|
| Primary | 实底 `#465B92` + 白字 14px/700 + 圆角 12px + 最小高 40px（推荐 44）；hover 品牌辉光 |
| Glow CTA | `#F9B0FF→#F796FF` 渐变 + grape 字 + 常驻辉光（主 CTA 级） |
| Ghost | 玻璃底 0.55 + 亮边 + blur(8) + 阴影 2/8；hover ice 底 + 阴影 4/16 |

全按钮共用 200ms ease；hover scale 1.02 / press .98（用独立 scale 属性，勿覆盖定位 transform）；自包含按钮 600ms 横向扫光、选中导航 700ms。

```

## 3. 常见坑排查表（≥10 项，踩过的人话）

> 前 4 条来自 web 端真实事故（01/02 文档记录），Flutter 侧同构复现风险最高。

| # | 现象 | 坑位与解法 |
|---|---|---|
| 1 | 移动端掉帧/发热 | **BackdropFilter 毛玻璃**每处一次离屏模糊，全站几十处=灾难。解法：GlassCard 基类统一实现；按 03 §1 降级链（低端设备/窗口缩小 → 0.92 高不透明实底）；弹层用 0.78 强玻璃少一层 blur；真机帧率验收 |
| 2 | 弹层被裁剪/画错区域 | **BackdropFilter 产生 stacking context**（web 端 fixed 弹窗被祖先毛玻璃困住的同源问题）。解法：弹层一律挂 Flutter Overlay 根级（`Overlay.of(context)`/`showDialog` root navigator），不在玻璃卡内 build |
| 3 | 断点切换时播放器黑屏/重建 | web 端「全屏锁横屏 → isNarrow 翻转 → 布局切换 → video 重建 → 黑屏」真实事故。解法：session 单例持有媒体，UI 只搬视图；**全屏期间冻结断点判定**（记录进入全屏前的宽度） |
| 4 | 切群/切房后旧会话把新会话踢掉 | web 端 `liveSessionRuntime` epoch 代际交接事故。解法：会话 owner 令牌（epoch），旧视图 cleanup 校验令牌，不匹配不 leave |
| 5 | 音频延迟/杂音/不同步 | WS 音频中继链路（采集→Opus 编码→WS→解码→播放）抖动缓冲策略决定体验。解法：先跑 06 文档 PoC-A 调缓冲（目标体感 <300ms）；播放端用连续 PCM 环形缓冲；采样率全程 48k 单声道不要中途重采样 |
| 6 | Windows 播不了直播/卡 | HLS 桌面弱环（03 文档 W4）。解法：media_kit(mpv) 验证；失败降级方案需用户拍板（外部播放器/浏览器） |
| 7 | 图片 401 破图 | **媒体 URL 必须带 Bearer**，Flutter 无原生支持。解法：dio 拉 bytes + 内存/磁盘缓存（LRU），不走 Image.network 裸 URL；缩略图永远用 320px 签名图，不全量拉原图 |
| 8 | GIF 不动画 | Flutter 原生不支持 GIF 动画帧（web 端 GIF 走原图是浏览器能力）。解法：gif 包/自绘解析，或服务端转格式（低优先级） |
| 9 | WS 掉线后状态漂移/红点不对 | 重连协议：心跳 ping/pong、resume 恢复、**重连成功后补拉一次对账**（红点/未读）。解法：连接管理器状态机照抄 01 §9 语义；令牌临期先 refresh 再连（防 WSREJECT 循环） |
| 10 | 字体不圆/中文发虚 | Fredoka/Nunito 只覆盖拉丁与数字。解法：三字体打包 assets；CJK 走 fontFamilyFallback（PingFang SC/Noto Sans SC）；`google_fonts` 运行时联网加载不可靠，必须离线打包 |
| 11 | 手势与滚动打架 | web 端 useTouchAxisGuard 经验：横向滑动手势要处理与垂直滚动的交叉轴让位。解法：GestureDetector 方向锁 + 手势竞技场；子组件横滑（图片预览/子群条）用自身手势并 stopPropagation 等价物（`GestureDetector` 独占 + RawGestureDetector team） |
| 12 | 上传大内存暴涨 | web 端 1GB+ 文件曾整块读入 OOM。解法：dio 流式 + 1MiB 分块 PUT；进度按真实字节聚合；取消调 DELETE 清理（幂等） |
| 13 | 滚动恢复位置错乱 | 列表返回要恢复滚动位置+已加载分页；恢复期间不播入场动画。解法：PageStorageKey/自管理 ScrollController + 位置记忆（按用户/分类/列表隔离，web 教训） |

## 4. 纪律红线清单（design.md 灵魂，违反=不像 Ayla）

1. **辉光 ≤3 处/屏**：只给爱莉身份、主 CTA、focus；窄屏降 30%
2. **爱莉专属样式不复用**：粉渐变气泡、光环呼吸、grape 强调——只有爱莉能用
3. **禁裸色值**：一切颜色走 Tokens 类；组件内不许散落 hex（web 端禁裸 hex 的翻译）
4. **reduced-motion**：`MediaQuery.disableAnimations` → 关闭全部位移/呼吸/扫光/流体背景，直接显示最终态；手势退化为直接控件
5. **手势必须有效等价路径**：每个 pager/下拉/边缘手势都有按钮/键盘路径（web 已全部具备，翻译时保留）
6. **图标用线性 SVG 风格（lucide_icons），禁止 emoji 当功能图标**；emoji 只出现在消息内容与表情包
7. **气泡/光环只表达运行事实**：在线状态 = 光环 + 文字标签双通道（不只看颜色）；看人数 null 显示「–」不写 0 冒充
8. **单材料 owner**：一张卡只保留一个材料层，内部布局块不叠玻璃/blur/整块阴影（web §4 纪律）

## 5. 实施顺序提醒（PoC 前置）

```
开写之前先确认两个 PoC 结论（决定架构，不能后补）:
PoC-A 音频 echo: 手机录一段 48k 单声道 → libopus 编码 → WS 发给本机 → 解码播放（体验延迟与抖动）
PoC-B HLS 三端: 三平台各放一段 SRS 样例流，验证播放器选型、延迟体感、跳边、黑屏恢复
（详细步骤见 06 开发步骤 §6）
开发主体顺序: M0 基座 → M1 认证 → M2 群聊 → M3 内容域 → M4 帖子 → M5 语音 → M6 直播 → M7 桌游+宽屏 → M8 平台打磨
先窄屏 Android 全功能，再 iOS（同一代码库补差异），最后 Windows
```
