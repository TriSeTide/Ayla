## 教训（给下一任）

1. **VM service 直连热载不可用**：`reloadSources` 需要 flutter tool 编排；夜里要热载就得把 `flutter run` 跑在**可见控制台**里（`Start-Process cmd /k flutter.bat run -d windows`），再用 SendKeys 发 `r`/`R`。
2. **UI 坐标**：`get_window_state` 返回的 UIA `frame` **就是屏幕坐标**（窗口在 (0,0) 时）。用截图比例换算会错——除非窗口正好最大化到 1920×1030。窗口未最大化时必须用 `window_bounds / screenshot_size` 现算比例。
3. **cua 会话会过期**：`list_windows` 等用**隐式会话**，报 `this session has ended` 时先 `start_session({})` 再调。
4. **playwright-mcp 截图落在 DSH profile cwd**（`C:\Users\ricer\.dsh\profiles\desktop\`），每次都要 Move 到证据目录。
5. **playwright MCP 参数名**：`browser_click{target}` · `browser_find{text|regex}` · `browser_evaluate{function}` · `browser_network_request{index, part}`（不是 ref/element/expression/number）。
6. **给 worker 发纠偏消息**：DSH 会话视图底部输入框 —— 用鼠标点输入框 + `SetKeys('^v')` 粘贴、**回车发送**（点那个圆形发送键在「生成中」时可能不生效，回车可靠）。
7. **点击要落在目标窗口**：先 `cua_driver.bring_to_front(pid, window_id)`（AttachThreadInput，能绕过前台锁），再 `SetCursorPos`+ `mouse_event`；只调 `SetForegroundWindow` 常常失败（点击会落到别的窗口）。
8. **`flutter run` 的 'r' 热载**：把 `flutter run` 跑在 WindowsTerminal 的 cmd 标签里，用 SendKeys 发 `r`；实测偶发不生效（控制台只回显一个 r），必要时直接 kill + 重启 `flutter run`（用户已授权）。
9. **web 别刷 URL**（用户明确要求）：SPA 整页重载会让每个接口重拉、截图停在骨架屏；**点导航跳转**才是真实体验。
