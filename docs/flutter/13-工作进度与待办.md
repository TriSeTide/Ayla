### 6.1 用户实测校准值（**优先于 web 原值**，已在代码注释标注）

### 6.2 库级约定与用户裁决（跨轮有效）

- **禁用态 = 按颜色降透明**：禁止整层 Opacity 包住含 BackdropFilter 的玻璃件（Impeller 拒绝且禁用态不变暗）⇒ 实现见 GlassSurface.dimAlpha 与 buttons.dart 的 dim 家族；
- **来源标签三域统一** = AylaSourceTag（live 徽章档度量），**容器各自决定**（滚动条 vs flex-wrap）；帖子标签的灰底是 web bug，不复刻；
- **卡片族悬停只有一套**（translate -2px + glass-shadow-hover，press .99）；**卡片上不放分享/转发键**（只出现在房头部）；
- **窄屏档一律由调用方注入**（AylaPrivateChatPane / AylaMessagesTabs / AylaGameRoomPlaceholder 的 narrow 参数惯例）：画布样张的固定宽舞台不等于宿主视口宽，**样张必须显式注入**；
