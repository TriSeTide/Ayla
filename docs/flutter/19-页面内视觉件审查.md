> **为什么有这份**：用户指出「组件库视觉组件都没做完吧。搜索域和个人主页域群内各种独立页面什么的，
> 审一遍啊，虽然复用组件多，但也不能漏」。
> 之前两轮清点只对了 `web/src/components/**` 与 `web/src/layout/**` 的**导出名**（149 个）——
> **页面文件（`web/src/pages/**`）里内联的视觉件从未审过**，那部分正是这份文档补的。
>
> **审查方法**：逐页读 JSX 结构 → 抽出「本页自有类名」（排除 `btn`/`field`/`icon-btn-40`/`skeleton` 等基元）
> → 对照 Flutter 库（`18-组件库清册.md` + `grep lib/`）判定「已覆盖 / 缺 / 属页面装配」。
>
> **结论**：页面大多是「**Directory 目录页骨架**（`directory-*` 筛选 + 内容 + `home-load-more`）+ 域名自有件」；
> 骨架与筛选已覆盖（`AylaDirectoryFilters` / `AylaDirectoryLoadMore` / `AylaAsyncState`），
