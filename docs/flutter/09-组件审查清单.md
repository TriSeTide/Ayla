### ✅ 已修

13. **`aurora_background.dart` 网格纹理画成实线**：CSS 是 `0–1px 全亮(.015) → 1–3px 渐隐(.008) → 3–4px 归零` 的柔和线（96px 周期），我画 1px 实线 → 已改 3 段渐变
14. **`CapsuleTag` tone 抽象越界**：web **无统一胶囊基类**，各胶囊独立定义且规格不同（`sakura`=auth.css 12px/ls.4/padding 6×14；`ice`=search.css **13px/padding 4×12**；`pink`=live.css），`glass`/`indigo` **无事实源** → 已加事实源边界表，标注其余 tone 须按各自 CSS 覆写
15. **`cssLinearGradient` 角度换算在非正方形盒子上错位**（重大，影响全站斜向渐变）：
    - CSS 渐变线长 `L = |W·sinθ| + |H·cosθ|`，而 Flutter `Alignment` 端点在**归一化空间**插值 → **仅正方形等价**
    - 实测 W=100/H=60/135deg：左上 t 偏差 **−0.582**、右下 **+0.582**（颜色位置差近一半）
    - 已按 CSS 规范重写（新增 `aspectRatio` 参数，端点 = `center ± (L/2)·dir` 换算回 Alignment，分量允许超出 ±1）
    - 验证：9 个采样点偏差 **0.0000**（左上 0 → 右下 1，135deg 终点正确落右下）
    - 已接入 `GlassButton`（glow 变体的 135deg，宽扁按钮偏差最大；用 `LayoutBuilder` 取真实宽高比）
