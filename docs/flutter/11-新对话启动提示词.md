## 四、Flutter ↔ CSS 语义差对照表（高频事故源，逐条防范）

| # | CSS 语义 | Flutter 实际行为 | 修法 |
|---|---|---|---|
| 1 | `box-shadow` **不在 border-box 内部绘制** | `BoxShadow` **铺满形状含内部** → 半透明面发灰、hover 时颜色染进按钮内部 | `AylaGlassShadow.ring`（挖空内部） |
| 2 | `background` 与 `border` **分离绘制** | `BoxDecoration` 同给 `gradient`+`border` 时**渐变盖住 1px 边框** | 拆层：底色 → 内高光 → **边框（独立层）** |
| 3 | `background-color` 过渡用 **premultiplied alpha** | `Color.lerp` **逐通道直插** → 从 `Colors.transparent`（**透明黑**）插值中途是**中性灰** | 零透明用**同色相** `color.withValues(alpha: 0)` |
| 4 | `overflow` 裁剪边界是 **padding box** | `SingleChildScrollView` 裁在**自己 content box** → 外阴影被裁断 | padding 放进滚动视图**内部** |
| 5 | `transition` 在**挂载时 `:hover` 已匹配** → 首帧直接到终点值，**不产生过渡** | `forward()` 从头播 → 行程被提前消耗 | 用 `setSweep(true, jump: true)` / `controller.value = 1.0` |
| 6 | `linear-gradient` 长度 `\|W·sinθ\|+\|H·cosθ\|` | `Alignment` 端点在**归一化空间**插值（只有正方形等价） | `cssLinearGradient(aspectRatio: 宽/高)`，在 `LayoutBuilder` 内生成 |
| 7 | `backdrop-filter: blur(24) saturate(1.4)` | 需 `ImageFilter.compose` | `GlassConfig.backdropFilter`；**saturate 分档**（24/18→1.4；8→无） |
| 8 | 7 个 `--glass-*` 阴影 token 全含 `--glass-inset` | `BoxShadow` 无 inset 变体 | `AylaInset.topHighlight(height)` / `AylaGlassInset.over` |
| 9 | `:hover` 是**状态谓词**（每帧求值） | `MouseRegion.onEnter/onExit` **只在指针移动时**触发 | 记录索引，在 **build 时求值** |
| 10 | `Stack` 越界装饰可见 | Flutter `Stack` 默认 `Clip.hardEdge` → **完全不可见**（但 `getRect` 报位置正确） | `clipBehavior: Clip.none` |
| 11 | 百分比位移的基准是**元素自身尺寸** | `AnimatedSlide`/`FractionallySizedBox` 基准是**直接 child** 尺寸 | 需精确像素时用 `TweenAnimationBuilder` + `Transform.translate` |
| 12 | CSS 负 `margin`（如 `margin-top: -8px`）= **上浮且占位减少** | `Transform.translate` 只做**视觉位移**、布局仍占满 → 撑破父容器 | `SizedBox(高-位移)` + `OverflowBox(alignment: bottomCenter)` |
| 13 | 无祖先 `DefaultTextStyle` 时用调试兜底 | **`OverlayEntry` 是独立子树**，页面 `Material`/`DefaultTextStyle` 传不进去 → `Text` 落到 `DefaultTextStyle.fallback`（**双下划线 + 红色**，用户称「黄线」） | 浮层一律走 `aylaOverlayEntry`（`widgets/overlays.dart`） |
| 14 | SVG 用 `currentColor` 继承 `body` 颜色 | `AylaIcon` 兜底链「显式 color → 祖先 `IconTheme` → `textPrimary`」，而 SDK 的 `ThemeData` 缺省会注入 **`IconThemeData(color: Color(0xDD000000))`**（肉眼即纯黑） | 主题必须显式设 `iconTheme`（`app_theme.dart` 已设 `textPrimary`） |

## 五、其他已踩过的坑（避免重复调查）

### 工具与流程
- **大段改写禁用字符串区间替换**：用 `edit` 工具精确替换；**禁止用 python 脚本替换目标文件**
  （用户明令：「别这样替换容易出错，用edit工具」）。脚本只用于**新建**文件或分片拼接。
- **`edit` 失败后必须立刻重新 `analyze`**：本会话因为「一条链里前一个 edit 失败、后一个成功」
  导致缺 import 漏到预览编译失败（`conversation_more_menu.dart` 的 `aylaOverlayEntry`）。
- **`grep` 结果要分清「注释」和「代码」**：我两次把注释里提到的 `height: 1.2` / `showBorder: false`
  当成实际代码，白跑一轮。
- **定位类问题先实测再改**：胶囊 64px、菜单落到 `(-16,151)`、垂直居中 116.0 都是**测出来**的；
  本会话用 `print('MEASURED …')` + `tester.getRect` 定位，比猜快得多。
- ⚠️ **`print` 里的 `${...}` 别转义**：写 `'x=${v}'` 而不是 `'x=\${v}'`（后者打印字面量）。
- **`/mnt/e`（drvfs）偶发 `EACCES`**：edit 的原子重命名会失败 → **直接重试**即可，文件不会损坏。

### Flutter / Dart 行为
- **`tester.pump()` 不带时长参数不推进动画时间** —— 会读到静止值，曾据此做两轮错误修复。
  正确：`await tester.pump(const Duration(milliseconds: 100));`
- **`previewTheme` 必须提供 `MaterialLocalizations` + `Overlay`**，否则含 `TextField` 的组件崩溃；
  ⚠️ **locale 必须传 `en`** —— `DefaultMaterialLocalizations.delegate` 只认英文，传 `zh_CN` 会**静默返回 null**。
- **`MaterialApp` 的 `home:` 必须包 `Scaffold`**，否则文字出现黄色双下划线。
- **不能在 `initState` 读 `MediaQuery`** → 放 `didChangeDependencies`。
- **条件表达式 `? 1 : 0` 是 int**，Dart 不提升为 double，传给 `Opacity.opacity` 会崩且 **analyzer 不报**。
- **`StackFit.expand` / `Center` 在无界高度下的陷阱**：`Stack(children:[Positioned.fill])` 在
  `Column(mainAxisSize.min)` 里会 `BoxConstraints forces an infinite height`；`Center` 在无高度约束下
  **会撑满父级**（顶栏模块项因此从 44 被撑到 64）。需要固定尺寸时用显式 `SizedBox(height:)`。
- **`BackdropFilter` 必须配裁剪**（`ClipRRect`/`ClipRect`）：模糊**不受布局尺寸限制**，
  缺裁剪会把背后**整块画布**糊掉（用户实测「底栏加了个遮罩挡住整个大画布」）。
- **`TabBadge` 内部自带 `Positioned`**：外层再套一层会触发 `Competing ParentDataWidgets` 断言。
- **`AvatarHalo` 在线时有呼吸动画** → 渲染尺寸会抖动；断言应量 **widget 属性**（`halo.size`）而非 `getRect`。
- **`AylaIconData` 不是常量表**（图标在 `kAylaIcons`）→ 用 `aylaIconByName('iconShare')!`。
- **换 `MaterialApp.home` 不会重建子树**（同类型 widget）→ 测试里改参数要用 `StatefulBuilder` 宿主。
- **跨 `pumpWidget` 换 widget 类型后再 `find`** 会同时命中新旧树 → 拆成两个独立 `testWidgets`。
- **选项卡「选中底」不许有过渡**：web 的 `.has-auroraqua-highlight:is(.is-active,.active) {
  background: transparent }` 是**瞬时**的（高亮块直接出现/消失）。给这个底色套
  `AnimatedContainer` 会让高亮块**渐显**，很拖沓（用户 2026-09-21 实报）。正确写法：
  `duration: active ? Duration.zero : <原时长>` —— hover 底色的过渡要保留。
- **零透明必须用同色相，不能写 `Colors.transparent`**：那是 `0x00000000`（**透明黑**），
  Flutter 的 `Color.lerp` **逐通道直插**（不按 alpha 加权）⇒ 中途会闪**中灰**
  （CSS 用 premultiplied alpha，故 web 无此现象）。零值写 `ice500.withValues(alpha: 0)` 之类。
- **同一行有多个浮层钮时，hover 必须分两层**：钮自身（各有各的 `:hover`）+ 行底联动
  （web `.channel-scene-row:has(<任一钮>:hover) .channel-scene { background: .18 }`）⇒
  两个状态（行级 / 钮级），否则悬停一个两个一起亮。
- **`.is-open` / `.is-active` / `:hover` 是三种不同状态**：常见合并成一个 bool 就是 bug。
  尤其「展开态只改 transform/几何、**不改颜色**」（`.channel-scene-*-toggle.is-open` 只 rotate 180°）。
- **预览宿主（Flutter web / CanvasKit）不认系统字体** ⇒ 中文全变**方框**。字体配置在
  `Ayla/flutter/.widget_preview/pubspec.yaml`（**独立工程**，不是主工程），已注册 `Noto Sans SC`；
  改它的 pubspec 后必须 `rm -rf .widget_preview/build` 再重启预览。详见 `13-*` §6.12。
- **依赖实测几何的定位要放进 `paint`**（`RenderProxyBox` + 自写 `performLayout` +
  覆盖 `applyPaintTransform` + 每次重建 `markNeedsPaint`），否则永远落后一帧
  （「子列表已到位、选项卡还在动」的穿透）。详见 `13-*` §6.10 / 6.11。
- **预览报 `Dependency … has errors!` 时先看宿主缓存时间戳**：`.widget_preview/build/*.cache.dill.track.dill`
  若是**改动之前**的（drvfs 上宿主监听不可靠）⇒ 旧 dill 与新源码接不上，并非代码错误。
  ⚠️ **新建文件（不只是改文件）几乎必然中招**：宿主的增量编译器只重编它**已经知道**的文件，
  新建文件的 create 事件在 drvfs 上常常收不到 ⇒ 表现为 `依赖 X 有错误` / `X has errors!`，
  且 hot reload 救不回来（该文件从未进入 dill）。判定方法：比对
  `ls --time-style=full-iso .widget_preview/build/*.track.dill` 与源文件 mtime，
  并用 `Get-CimInstance Win32_Process`（筛 `widget_preview`）看宿主与 `frontend_server` 的启动时间
  —— 宿主启动时间早于新文件创建时间即可确诊（2026-09-21 A5 实录：宿主 19:49 起、文件 23:42 建）。
  先用 `dart analyze lib` + `flutter test` 自证（能编译就通），再请用户
  `bash tool/preview-up.sh --stop && rm -rf .widget_preview/build && bash tool/preview-up.sh`。
  ⚠️ 顺带：给已有样张**改类的字段集合/继承**（如 `_Cell` → `_Stage`）hot reload 一律拒绝，也只能冷启动。
- **CSS flex 的 `min-width: auto` 语义要按 `overflow` 判**：带 `overflow: hidden` 的 flex 项
  其自动最小尺寸是 **0**（可被压到 0，由 `text-overflow: ellipsis` 兜底），而带 `flex-wrap: wrap`
  的那组 min-width = min-content（最长一项）。⇒ 一行放不下时**先压前者、最后才让后者折行**。
  本项目事故：`PostCard` 头部把「昵称保留 64px」当成硬约束，导致 360 宽卡上标签组只剩 199px
  < 所需 222px ⇒ 标签折行（既有测试失败，2026-09-21 修复）。详见 `13-*` §6.20。
- ⚠️⚠️ **依赖隐式动画的子树，Element 结构必须跨状态稳定**：`TweenAnimationBuilder` /
  `AnimatedOpacity` / `AnimatedRotation` / `AnimatedScale` 都在 `initState` 里把
  `tween.begin` 设成 `end` ⇒ **子树被重建就等于「直接跳到终值、没有动画」**。
  只要「按状态增减包装器」（如 `collapsed ? ExcludeSemantics(child: x) : x` —— 根 widget
  类型一变就重建整棵树）就必然中招；改成**包装器恒在 + 只翻转标志位**（`excluding:` / `ignoring:`）。
  本项目事故：A5 收起时**球瞬间消失**（组在滑、球不动），而**只断言终值的测试全绿**。
  验证动画必须量**中间帧**：位置用 `tester.getRect` 的像素；透明度用
  `FadeTransition.opacity.value`（**活值**——`AnimatedOpacity.opacity` 是**目标值**，
  动画中途读它也永远是终点，会把「有动画」误判成「跳变」）。详见 `13-*` §6.21。
- ⚠️ **Flutter `Slider` 传 `divisions` 会让拇指「不跟手」**：`divisions != null` ⇒ `isDiscrete`
  ⇒ `positionController.animateTo(value, curve: easeInOut)`（`slider.dart:1292–1300`，
  时长 `_positionAnimationDuration = 75ms`）——拖动时拇指被动画化、**追不上指针**，
  而你自己画在它后面的轨道是即时重建的 ⇒ 看起来「条子跟手、滑块在拖沓/错位」。
  web 的原生 `input[type=range]` 是跟手即时；要 step=1 的整数语义就**不传 `divisions`**、
  在 `onChanged` 里 `roundToDouble()`。验法：拖动后**只推进一帧**，像素扫拇指（白环质心）
  应落在期望位置 ±2px（修前扫不到）。
- **「加大圆角」在细条上有几何上限**：`border-radius: 999px` 会被浏览器/Flutter 夹到 `高/2`
  ⇒ 4px 条的端帽 R 最大就是 2（半圆），想更圆**只能加厚**（A5/B1-2 的语音音量条已按用户校准
  4 → 5px）。量「有没有圆角」用**左端逐行覆盖率轮廓**（圆帽是透镜形、中心行最高；方角端各行相等），
  别只看 `getRect` 或肉眼。
- **同一元素两个方向可以有不同的过渡时长**：CSS 的基础规则与 `.is-collapsed` / `.is-active`
  规则**各带一份 `transition`**，按当前命中的规则生效（A5 球的 `transform`：收起 200ms、
  展开 **150ms**；`opacity` 两向都是 200ms）⇒ 位移与透明度要拆成两个动画宿主，别合并成一条。
- **滚动跟随类组件（回顶钮 / 吸顶条）的三个首帧陷阱**：`viewportDimension`/`pixels` 在 layout 前是
  `null`（用 `hasViewportDimension`/`hasPixels` 守卫）；`didChangeDependencies` 里 `setState`
  会让 `_MediaQueryFromView` 依赖断言失败（首轮排到 postFrame）；**`ScrollController.attach()`
  不 `notifyListeners`**（首帧 `positions` 为空 ⇒ 要在 build 里补一次幂等 postFrame 绑定）。
  详见 `13-*` §6.19 与 skill。
- **CSS 变量未定义 = 该声明整条作废（回落初始值），别当成"没写"**：`--glass-bg-hover` 在 web
  **全历史从未定义**（4 处引用、零定义）⇒ `background: var(--glass-bg-hover)` 按规范属
  「invalid at computed-value time」，**简写整体回落** = 底色透明（边框/模糊/阴影保留）。
  用 `git log -S'--token:' -- <路径>` + 读 `dist/assets/*.css` 验证后再判「照实渲染还是按意图修」，
  并请用户拍板。详见 `13-*` §6.21。
- **`Semantics(label:)` 不会覆盖子 `Text` 的标签**（Flutter 会把两者拼起来，如
  `收起媒体控制\n›`），而 web 的 `aria-label` 是**覆盖**内容作为可访问名 ⇒ 装饰字形/图标要
  自己 `ExcludeSemantics`。另：`SemanticsNode.hasFlag` 已弃用，用
  `flagsCollection.<flag>.toBoolOrNull()`。
- **测试作用域要收紧到组件内**：`previewTheme` 的 `Material` 自带一层
  `AnimatedDefaultTextStyle` ⇒ `find.ancestor(of: find.text(...), matching: byType(...))`
  会 "Too many elements"；用 `find.descendant(of: 组件面, ...)`。`AnimatedContainer` 也**没有**
  `width`/`height` getter（折进了 `constraints`）。另：`previewScope` 的
  `Overlay(initialEntries:)` **只在首次创建生效** ⇒ 同一 `testWidgets` 里第二次 `pumpWidget`
  换 props / 换视口都不生效，一律拆成独立用例（§6.19 / §6.21）。
- **拖动/手势类必须走原始指针**：web 的阈值常是 5px 这类小值，而 Flutter 手势识别器要等
  `kTouchSlop`(18px) 才回调 ⇒ 用 `Listener` 的 `onPointerDown/Move/Up` 做几何；若 web 有
  `touch-action: none`（拖拽期间页面不滚动），再挂一个**回调留空的**
  `GestureDetector(onVerticalDrag*)` 只为赢下竞技场，并写「背后放 ListView + 拖动」的测试锁
  `controller.offset == 0`。详见 `13-*` §6.21。

## 八、与用户协作的节奏（本会话总结，务必遵守）

- 用户会**逐条**指出不符项（顺序、圆角、尺寸、hover、扫光、对齐…）。**不要辩解，先核实再改**；

  此时**必须把偏离 web 的事实与理由写进代码注释**，避免后面的 agent 又「复刻」回去。
