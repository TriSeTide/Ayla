## 四、Flutter ↔ CSS 语义差对照表（本项目高频事故源，务必逐条防范）

| # | CSS 语义 | Flutter 实际行为 | 修法 |
|---|---|---|---|
| 1 | `box-shadow` **不在 border-box 内部绘制** | `BoxShadow` **铺满形状含内部** → 半透明面发灰、hover 时颜色染进按钮内部 | `AylaGlassShadow.ring`（`Path.combine(difference,…)` 挖空内部） |
| 2 | `background` 与 `border` **分离绘制** | `BoxDecoration` 同给 `gradient`+`border` 时**渐变盖住 1px 边框** | 拆层：底色 → 内高光 → **边框（独立层）** |
| 3 | `background-color` 过渡用 **premultiplied alpha** | `Color.lerp` **逐通道直插** → 从 `Colors.transparent`（**透明黑**）插值中途是**中性灰** | 零透明用**同色相** `color.withValues(alpha: 0)` |
| 4 | `overflow` 裁剪边界是 **padding box** | `SingleChildScrollView` 裁在**自己 content box** → 外阴影被裁断 | padding 放进滚动视图**内部** |
| 5 | `transition` 在**挂载时 `:hover` 已匹配** → 首帧直接到终点值，**不产生过渡** | `forward()` 从头播 → 行程被提前消耗 | 直接 `controller.value = 1.0` |
| 6 | `linear-gradient` 长度 `\|W·sinθ\|+\|H·cosθ\|` | `Alignment` 端点在**归一化空间**插值（只有正方形等价） | `cssLinearGradient(aspectRatio: 宽/高)`，在 `LayoutBuilder` 内生成 |
| 7 | `backdrop-filter: blur(24) saturate(1.4)` | 需 `ImageFilter.compose(outer: ColorFilter.matrix, inner: blur)` | `GlassConfig.backdropFilter`；**saturate 分档**（24/18→1.4；8→无；app.css 3585→1.2） |
| 8 | 7 个 `--glass-*` 阴影 token 全含 `--glass-inset` | `BoxShadow` 无 inset 变体 | `AylaInset.topHighlight(height)` / `AylaGlassInset.over` |
| 9 | `:hover` / `:focus-visible` 是**状态谓词**（每帧求值） | `MouseRegion.onEnter/onExit` **只在指针移动时**触发 | 记录索引，在 **build 时求值** |
| 10 | `Stack` 越界装饰可见 | Flutter `Stack` 默认 `Clip.hardEdge` → **完全不可见**（但 `getRect` 报位置正确） | `clipBehavior: Clip.none` |
| 11 | `AnimatedSlide.offset` / `FractionallySizedBox` 的百分比基准 | 是**直接 child** 的尺寸，不是内容尺寸 | 需精确像素时用 `TweenAnimationBuilder` + `Transform.translate` |

## 五、其他已踩过的坑（避免重复调查）

- **`tester.pump()` 不带时长参数不推进动画时间** —— 我一直读到静止值，
  误判"扫光卡住"，据此做了**两轮错误修复**。正确：
  `await tester.pump(const Duration(milliseconds: 100));`
- **`previewTheme` 必须提供 `MaterialLocalizations` + `Overlay`**，
  否则含 `TextField` 的组件在预览/测试中**直接崩溃**。
  ⚠️ **locale 必须传 `en`** —— `DefaultMaterialLocalizations.delegate`
  只认英文，传 `zh_CN` 会**静默返回 null**。
- **不能在 `initState` 读 `MediaQuery`** → 放 `didChangeDependencies`。
- **条件表达式 `? 1 : 0` 是 int**，Dart 不提升为 double，
  传给 `Opacity.opacity` 会崩且 **analyzer 不报** → 写 `1.0` / `0.0`。
- **`MaterialApp` 的 `home:` 必须包 `Scaffold`**，否则文字出现黄色双下划线。
- **大段改写禁用字符串区间替换**（曾把中间 134 行的类一起删掉且无法从 git 恢复）
  → 用 `edit` 工具精确替换。
- **参数含义要按顺序理解**：`--auroraqua-ease` = CSS `ease` = `Cubic(.25,.1,.25,1)`。
