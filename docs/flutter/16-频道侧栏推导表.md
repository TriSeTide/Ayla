## 八、自建 sticky + 动态裁剪（沿用 `13-*` §6.8/§6.10/§6.11）

1. 滚动内容里**只放占位** `SizedBox(height:40, key: slotKey)`；行本体画在顶层 `Stack` 的 `Positioned`；
2. 位置公式：`y = max(top, min(natural − scroll, viewportH − 40 − bottom))`（**top 优先**）；
3. **同帧定位**：`_StickyRowLayer`（`SingleChildRenderObjectWidget` + `RenderProxyBox`）在 **`paint`** 里
   读占位 `localToGlobal` → `context.paintChild(child, offset + y)`；三个细节一个都不能少：
   `performLayout` 自己写（`size = constraints.biggest` + `child.layout(tightFor(width))`）、
   **覆盖 `applyPaintTransform`**、**每次重建 `markNeedsPaint()`**；
4. 几何用 `GlobalKey` 实测；`_scheduleMeasure(ticks:30)` 追踪窗口覆盖 300ms 隐式动画；
5. **动态裁剪**（`useSidebarContentClip` 28–53 等价，paint-only）：
   `start = max(viewportTop, header.bottom + gap, dropdown.top)`、
   `end = min(viewportBottom, nextHeader.top − gap, dropdown.bottom)` → `ClipRect` 自定义 clipper；
6. 「滚到吸顶位」= `animateTo(natural − stickyTop)`；
7. **验收判据**：动画每一帧「行 ↔ 其下拉首行」距离恒定（上一版实测 `gap=42`）。
