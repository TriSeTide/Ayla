### R2（P0）外阴影裸 `boxShadow:` 13 处，ring 只有 1 处真实调用

**事实**：`glass.dart:225-235` 明确记录——CSS 的 `box-shadow` **不在 border-box 内部绘制**，而 Flutter 的 `BoxShadow` **会铺满形状含内部**；B4 已把 `_OuterShadowPainter` 提升为公共 API `AylaGlassShadow.ring`（`glass.dart:236-292`）作为修法。

**实际调用情况**（全量 grep）：
- `AylaGlassShadow.ring` 真实调用 **仅 1 处**：`widgets/profile_and_filters.dart:887`（`.directory-filter` hover 的 `--glass-shadow-nav`）。
  另 `primitives.dart:617` 只是一句注释（声称改由 ring 绘制，**该文件内无 ring 调用**）。
- 裸 `boxShadow:` 仍存在于 **13 处**，其中 8 处垫在**半透明面层之下**（阴影透过卡面可见）：

| 位置 | token | 面层透明度 | 影响 |
|---|---|---|---|
| `conversation_more_menu.dart:611` | `AylaShadows.glass` (.2) | .78 强玻璃 | 菜单内部偏冷偏灰 |
| `dialogs.dart:528`（AylaModalCard） | `modal` (.30) | .78 | 弹层内部偏灰 |
| `privacy_sheet.dart:391` | `modal` (.30) | .78 | 同上 |
| `directory_controls.dart:1102` | `compact` (.10) | .55 | 选择器面板内部偏灰 |
| `group_card.dart:1188`（_GlassCardShell） | `glass`/`glassHover` (.2) | .55 | 群卡内部发灰 |
| `group_card.dart:1570`（_ListItemShell） | `compact`/`glassHover` | .55 | 列表行内部发灰 |
| `media_interaction.dart:551` | `card` | .55 | 刷新指示器 |
| `glass.dart:749`（**GlassButton**） | `compact`/`button`/`buttonHover`/`glow` | .55（ghost）/不透明（primary） | ghost 变体内部染色；primary 不受影响（不透明底） |

其余 5 处（`buttons.dart:237/318/381/552/651`）更直接：`boxShadow` 与面层写在**同一个 BoxDecoration** 里（阴影与底同层绘制）。其中 `AylaIconButton`(237)、`AylaToolButton`(552)、`AylaMsgActionButton`(651)、角标 FAB(318) 都是 .55 玻璃底 → 内部被叠 `rgba(70,91,146,.1)`（hover .15）；`AylaCreateFab`(381) 是不透明 indigo 底，无影响。

**判定**：R2 是 **R1 的下游症状**——因为阴影层是手搓的，就顺手用了最省事的 `boxShadow`。
**建议**：把这 13 处的阴影层换成 `AylaGlassShadow.ring`（形状外绘制），或按 R1 收敛到 `GlassSurface`。
**复核口径**（写进验收）：修完用像素取样验「卡内 vs 紧贴卡片的背景」，而不是看属性值。

### R2b（P0）`--glass-shadow-nav` 在两个宿主缺失

**事实链**：
- web `auroraqua.css:175-185`：`.auroraqua-nav-highlight` 恒定带 `box-shadow: var(--glass-shadow-nav)`（`0 0 8px rgba(157,191,230,.3)`，选中胶囊的冰蓝柔光）。
- Flutter `AylaNavHighlight`（`primitives.dart:477-700+`）绘制了背景渐变、1px 亮边、扫光，**没有绘制外阴影**；文件内注释（`primitives.dart:606-617`）说明「阴影不能挂 BoxDecoration（会把胶囊内部染蓝）→ 故阴影改由 `AylaGlassShadow.ring` 单独绘制」。
- 但全库 grep `AylaShadows.nav` / `AylaGlassShadow.ring`：只有 `.directory-filter` 宿主补上了 ring（`profile_and_filters.dart:887`）。
  **两个宿主没有补**：`AylaLayoutSwitch`（`primitives.dart:184` 挂 AylaNavHighlight）、`AylaSegmentedTabs`（`primitives.dart:425`）——其选中胶囊当前**没有任何外阴影**。

**结论**：这是「删掉裸 `boxShadow` 后忘了补 ring」的遗留，属真缺失（不是重复）。
**建议**：修 R2 时一并给 `AylaNavHighlight` 补上 ring（放在胶囊层之下），并在预览里对 `.layout-switch` 选中胶囊做**像素取样**验证（胶囊外应有冰蓝柔光）。

### R7（P1）入场动画 2 套私有，库内无公共件

| 实现 | 位置 | 能力 |
|---|---|---|
| `_RevealItem` | `group_card.dart:1217-1270` | opacity 0→1 + y 20→0，300ms `--auroraqua-ease-out`，支持 `delay`，reduced-motion 直接到位 |
| `_EnterFrom` | `profile_and_filters.dart:677-737` | 同配方，支持任意方向 `offset`，无 delay |

**建议**：抽公共 `AylaRevealItem`（`delay` / `offset` / `enabled`）+ `AylaListEntryMotion`（`suppressed` / `replayKey` / 可传步长），先迁移这两处私有件，B5 直接复用。
