# Ayla Flutter 复刻 · 新对话实施提示词（第一步：M0 基座）

> 用途：给用户开新对话实施时**整段复制粘贴**的提示词。
> 配套：`06-开发步骤.md` 是主操作手册；本文件只承载「第一步（M0 基座）」的启动上下文。
> 用法：新对话 → 粘贴下方「==== 提示词正文 ====」到「==== 提示词结束 ====」之间的全部内容 → 发送。实施完成后把结果带到新对话继续下一步（届时提供新的提示词段）。

---

## 使用说明（给用户，不发给实施 agent）

1. **开新对话**，把下面正文整段粘进去（正文自包含，实施 agent 不需要看本会话历史）。
2. 实施 agent 会先读必读材料、探查环境，然后按 M0 步骤清单执行；它只做 M0，不越界到 M1+。
3. 完成后把实施 agent 的报告带回来（或让它落盘到 `Ayla/docs/flutter/实施记录/`），我们接着出第二步提示词（M1 认证 / 或按实际进度调整）。
4. **提交时机**：M0 完成、你验收后，再让它 commit（提示词内已包含提交纪律）。
