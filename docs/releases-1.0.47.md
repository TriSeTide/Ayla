Ayla 1.0.47 更新内容

【直播 · 黑屏修复（重要）】
- 修复全屏观看时直播黑屏、且刷新/重试都没反应的问题。
- 修复网络抖动或播放卡死后，直播停在「播放失败」不再自动恢复的问题。
  现在会在 60 秒内自动重试，不再需要手动点重试。
- 修复窗口最大化/还原/拖动改变大小导致画面闪黑的问题。
- 修复切到后台再回来直播不自动续播、需要手动刷新的问题。
- 修复小窗开着时进直播间，画面被两路播放器抢占导致黑屏的问题。

【直播 · 延时大幅降低】
- 与推流端配合调整关键帧间隔，直播延时从 1 分多钟降到 4~6 秒。
- 起播更快：进直播间几乎立刻出画面。
- 长时间观看延时不再累积。

【直播 · 刷新键】
- 修复「刷新」键点了没用的问题，现在会真正跳到直播最新画面。

【拉流线路】
- 拉流改走独立高速线路（volx），不再占用有限的备用带宽，
  高峰期更稳定、更少卡顿。
- Web 端与客户端同步生效。

【技术说明】
- 本次为服务端 + 客户端配套更新：SRS 分片由 16.6 秒调整为 1 秒、
  关闭 GOP 缓存积压；客户端补齐了贴边播放与自愈重连逻辑。
- 建议所有用户更新。
