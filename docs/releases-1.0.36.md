Ayla 1.0.36 更新内容

【直播全屏（手机，重要）】
- 修复点全屏键后「横屏一瞬又退回竖屏、看不到全屏画面」的问题。
  根因是旋转导致整个直播间页面被重建，全屏层被连带销毁。现已彻底修复，
  点全屏可正常进入全屏直播，退出也恢复正常。

【直播全屏（电脑，重要）】
- 电脑端点全屏键现在是**真正的全屏**：窗口铺满整块显示器、标题栏与任务栏隐藏；
  按 ESC 即可退出全屏。

【直播小窗（手机，重要）】
- 直播小窗可以「脱离应用」了：点小窗上的脱离键会进入系统画中画，
  **App 退到后台、切到别的应用也能继续看直播**；在小窗里观看同样计入在看人数。
- 修复小窗双指缩放手势方向相反的问题：现在是张开变大、收拢变小。

【直播小窗（电脑，重要）】
- 电脑端小窗也能脱离应用了：会弹出一个独立的置顶小窗，
  主窗口最小化或被其他窗口挡住时依然能看到直播，同样计入在看人数。

【悬浮球脱离应用（手机 / 电脑）】
- 语音房 / 直播间的悬浮球现在可以脱离应用：切到其他应用后仍可见，点一下即可回到对应会话。
- 手机上首次使用会引导开启「显示在其他应用上层」权限；未开启时会明确提示，不会毫无反应。

【说明】
- 苹果 iOS 受系统限制，暂不支持画中画与跨应用悬浮窗，功能会停留在应用内，特此说明。

建议所有用户更新。
