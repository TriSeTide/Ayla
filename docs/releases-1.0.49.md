Ayla 1.0.49 更新内容

【存储位置优化（重要）】
- 所有本地数据固定存放在程序目录下的 data/ 文件夹，不再散落到系统盘的隐藏目录。
- 修复更新包长期堆积的问题：历史版本安装包会自动回收，此前曾累积到 7.79 GB。
- 凭据改用系统级加密存储，位置同样在程序目录内。
- 如果 Ayla 装在 Program Files 这类受保护目录，数据会自动落到
  「本地应用数据」下的 Ayla 目录，应用照常使用。

【稳定性】
- 修复偶发的「数据目录不可写」误判，该问题会导致登录状态读取失败。

【说明】
- 本次为客户端更新，建议所有用户更新。
- 直播播放的进一步优化正在单独分支验证，通过后会另行发布。
