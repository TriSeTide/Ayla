# Ayla 个人主页重制与头像跳转 —— 交付报告

> 涉及：后端 `GET /users/<id>/`、他人主页、头像全局跳转、消息气泡头像。
> 范围：`Ayla/web`（React 18 + Vite + TS + Zustand）+ `Ayla/backend`（Django）。

---

## 一、需求

1. 重制个人主页：优化布局样式、风格统一、返回改为返回键；
2. 进入他人个人主页：**所有有头像的界面**点击头像可进个人主页；
3. 群聊与私信聊天界面：气泡左右添加发送者头像；
4. 他人主页展示「添加好友」按钮（非好友时）。

## 二、后端

### 新增接口 `GET /users/<id>/`

`backend/apps/accounts/views.py` `UserDetailView`：

- 返回 `UserPublicSerializer` 全部字段 + `relation` 字段；
- `relation` 取值：`self`（当前用户）/ `friend`（已是好友）/ `pending_sent`（我发起的申请待处理）/ `pending_received`（对方申请我）/ `none`（无关系，可加好友）；
- 路由：`backend/apps/accounts/urls.py` → `users/<str:user_id>/`。

测试：`apps/accounts/tests/test_friends.py` 新增 `TestUserDetail` 5 项（none/self/friend/pending_sent/404），全 10 项通过。

## 三、前端

### 3.1 他人主页 `UserProfilePage`（/user/:id）

- 顶部：glass 返回键（icon-btn-40 + navigate(-1)）+ 标题「个人主页」；
- 资料卡（solid-card）：大头像（光环）+ 昵称 + @用户名 + 在线徽标 + 签名；
- 操作区按 `relation`：
  - `none` → 「添加好友」（发申请后变 pending_sent）+ 「发消息」；
  - `pending_sent` → 「申请已发送」（禁用）；
  - `pending_received` → 「对方已发起申请，去消息中心处理」；
  - `friend` → 「发消息」；
  - `self` → 重定向 /profile。
- 路由：`App.tsx` `/user/:userId`。

### 3.2 全局头像跳转

- `Avatar` 组件新增 `onClick` / `ariaLabel`：可点击时渲染为 button（`.avatar-halo-btn`，重置默认样式 + 光环 + focus-visible）；
- **全局导航单例** `utils/navigation.ts`：`registerNavigate` / `navigateTo` / `goUserProfile`；
  - 背景：`VoiceMemberRow` / `PrivateChatPane` / `MessageList` 等在测试中可能被无 `<Router>` 直接渲染，用 `useNavigate` 会抛错；
  - 方案：子组件渲染期不调 hook，点击时调单例；`App.tsx` 内 `<NavigateBridge/>`（Router 中）注册真正 navigate；未注册时静默 no-op。
- 接入界面：PostCard（帖子作者）、CommentList（评论作者）、PostDetailPage（详情作者）、ConversationList（私聊对端）、MessageList 气泡（发送者）、PrivateChatPane（对端）、WideMessagesSidebar（好友）、MessagesPage（好友）、SearchPage（用户结果）、GroupInfo（群成员）、VoiceMemberRow（语音成员）；
- 自己的头像 → /profile；他人 → /user/:id。

### 3.3 消息气泡头像

- `MessageBubble` 新增 `senderAvatar` / `senderAvatarLabel` / `onSenderClick`：peer 行头像在左、self 行头像在右（`msg-row` flex）；
- `MessageList` 从 `conversation.members` 映射 sender_id → avatar/label，传给气泡并接点击；
- `msg-actions`（引用/撤回）移入 `msg-body` 内（气泡下方），`msg-row.self .msg-actions` 右对齐。

### 3.4 ProfilePage 重制

- 返回从「文字按钮」改为返回键（icon-btn-40 + IconBack + `navigate(-1)`）；
- 标题「个人页」→「个人主页」（与 UserProfilePage 统一）。
