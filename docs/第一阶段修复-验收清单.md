**注意**：
- ⚠️ 当前实现已添加时间戳字段和工具函数，但**页面逻辑尚未使用过期检查**
- ⚠️ 需要在各页面的 `useEffect` 中调用 `isXxxStale()` 并在过期时重新加载
- ⚠️ 这是第一阶段遗留工作，建议在集成验证时补充

## 已知遗留问题

### ⚠️ 1. 页面未使用缓存过期检查
**问题描述**：
- 虽然 4 个 store 都增加了 `lastFetched` 字段和 `isXxxStale()` 工具函数
- 但页面的 `useEffect` 中只检查了 `if (xxx.length > 0) return`
- **没有增加** `if (!isXxxStale()) return` 的过期检查逻辑

**影响**：
- 用户刷新页面后，如果 store 中已有数据（例如从预加载获得），且未超过 60 秒
- 页面不会触发重新加载（符合设计）
- 但如果超过 60 秒，页面**仍然不会自动重新加载**（缺少过期检查）

**推荐修复**：
在以下页面的 `useEffect` 中增加过期检查：
- `VoiceHubPage.tsx`：`if (channels.length > 0 && !isVoiceStale()) return;`
- `PostsHubPage.tsx`：`if (posts.length > 0 && !isPostsStale()) return;`
- `LiveHubPage.tsx`：`if (channels.length > 0 && !isLiveStale()) return;`
- `HomePage.tsx`（会话列表）：`if (conversations.length > 0 && !isChatStale()) return;`

### ⚠️ 2. 直播间大厅页面未添加刷新按钮
**问题描述**：
- 子代理报告已修改 `LiveHubPage.tsx`，但该页面位于 `Ayla/web/src/pages/LiveHubPage.tsx`
- 实际文件状态显示 `LiveHubPage.tsx` **未被修改**（不在 `git status` 中）

**影响**：
- 直播间大厅页面没有手动刷新按钮
- 用户只能通过刷新浏览器来更新列表

**推荐修复**：
参考 `VoiceHubPage.tsx` 的实现（L194-200），在 `LiveHubPage.tsx` 增加刷新按钮。
