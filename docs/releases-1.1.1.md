# Ayla 1.1.1 更新内容

## 全新的窗口标题栏（Windows）

- **去掉系统原生标题栏**，换成 Ayla 自己的标题栏：左上角品牌标识，右上角最小化 / 最大化 / 关闭三个按钮，悬停有反馈，关闭键悬停变红。
- **启动默认最大化**。
- 窗口化时窗口有**圆角、冰蓝色边线和投影**；最大化时自动收成直角（和系统其它应用一致）。
- 从最大化还原时，窗口大小**按最大化时的比例缩小 20% 并居中**，不再是固定尺寸。

## 修好顶部拖不动的问题

- 顶部整条区域（含标题栏与导航栏之间的空隙）都可以**拖动窗口**，双击可以最大化/还原。
- 拖动不再需要先移动一段距离才响应，按下拖动就生效。

## 窗口图标重绘

- 最小化 / 最大化 / 关闭三个图标按 Ayla 图标库的同一套画法重绘（此前最大化图标有缺线）。

## 其它

- 退出直播全屏后不再冒出系统标题栏。
- 清理了两处界面文案里的乱码字符。

【说明】
- 本次为客户端更新，服务端未变动。
- 更新后需要**完全退出并重新打开**才能看到新的窗口边框（窗口 chrome 是原生层，热重载不生效）。
