Ayla 1.0.18 更新内容

【聊天】
- 修复群聊不显示他人头像与昵称：成员表加载时序问题（私聊本无此问题）。
- 修复手机端返回键直接跳回主页：现在逐级返回上一级，群内同样生效。
- 修复群内帖子详情按返回会跳出群、跑到帖子大厅的问题。
- 修复头像点击后返回落点错误的问题。
- 修复群内桌游房顶部多出一条空白带的问题。

【头像在线状态】
- 所有页面头像的在线状态改为实时更新，无需刷新。
- 补齐顶部栏、个人资料、搜索用户行、分享面板等多处的在线状态接线。

【语音房】
- 修复群内、群外语音房窄屏界面中部内容区四周贴边、没有留白的问题。

【发图】
- 修复直播间弹幕发图、帖子发图、帖子评论发图三处按钮点了没反应的问题。
- 修复群内发帖同类问题（发图按钮失效）。

【实时刷新】
- 群详情入群申请实时更新：新申请会直接出现，被处理后自动消失。
- 好友添加 / 删除双向实时通知，双方列表与搜索结果同步更新。
- 群表情包变更实时同步给群内所有成员。
- 同一账号多端之间，置顶与隐藏会话的操作实时同步。
- 爱莉资料（头像 / 昵称）变更实时更新到所有显示位置。

【本地存储】
- 图片、语音改为按需缓存：永久类资源（帖子图、评论图、表情包、头像、直播封面）
  不再占用本地空间。
- 查看图片先存缩略图，点开大图后才保存原图。
- 语音点击播放时才保存。
- 文件消息改为手动点击保存。
- 视频只在点击播放时缓存，仅保存首帧缩略图。

【稳定性】
- 修复录音器释放时的插件异常，减少偶发崩溃。

建议所有用户更新。
