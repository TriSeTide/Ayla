## 技术架构说明

### 统一内容入场动画原语

```
useRevealOnEnter(active) → {step, revealed}
        │ 双 rAF（首帧隐藏 → 过渡显示）
        ▼
   className="reveal" + (step===1 ? "is-in")
        ▼
   base.css：opacity 0→1 + translateY(8px→0)，180ms ease-out
   prefers-reduced-motion：只保留透明度渐变
```

### 帖子详情加载链路（并行）

```
进 /posts/:id
  └─ Promise.all([
        GET /posts/:id/,
        GET /posts/:id/comments/,
        GET /favorites/?type=post,
     ])
  总可见时间 ≈ max(RTT₁, RTT₂, RTT₃) ≈ RTT₁
```

### 评论实时推送链路

```
用户 A 发评论
  └─ views.CommentListView.post
      ├─ services.create_comment(...)
      └─ services.broadcast_comment_created(post, serialized, count)
           └─ group_send 到帖子可见性对应组（public→feed 组 / group→会话组 / friends→作者）
                └─ ChatConsumer.comment_created → send_json
                     └─ 前端 chatWS.onFrame → PostDetailPage 乐观插入/移除 + 计数
```

### 前端路由懒加载

```
App.tsx：React.lazy(每个页面) + Suspense(<RouteFallback/>)
首屏：只加载当前路由 chunk（HomePage 等）
其余：进入对应路由时才请求对应 chunk
```
