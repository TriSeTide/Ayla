Ayla 1.0.23 更新内容

【滚动（本次重点，全部对着网页端逐行复刻）】

1. 宽屏群聊右侧滚动条方向反了 —— 已修复。
   现在滚到底，条在最下面；滚到顶，条在最上面。
   直接拖动条也不会再拖反。

2. 直播间弹幕不自动滚到底 —— 已修复。
   停在最新位置时，每来一条新弹幕都会自动跟到底。
   注意：如果你正往上翻看历史，新弹幕不会打断你，
   只会亮出「有新弹幕 ↓」，点它才跳回最新。

3. 语音房内聊天不自动滚到底 —— 已修复。
   行为与直播间一致：在底部就自动跟随，上翻则不打断。

4. 聊天（群聊 / 私聊）回到底部与消息跳转 —— 已修复。
   - 点右下角「回到底部」现在是一步到位，不再有那段慢慢滑的动画
     （与网页端一致）；
   - 点未读 / @我 / 回复标签跳到目标消息，现在也是立即定位并居中；
   - 图文消息里图片加载出来撑高列表后，列表不会再脱离底部。

【其他】
- 三个直播入口（一级直播间 / 群内直播 / 开播控制台）的弹幕滚动
  行为已统一。

建议所有用户更新。
