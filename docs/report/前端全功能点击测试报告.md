# Ayla Web 前端全功能点击测试报告

> 日期：2026-08-15（晚）
> 范围：Ayla/web 全部界面与主要交互，**窄屏（375×760）+ 宽屏（1440×900）两种形态逐一点击测试**

## 二、覆盖清单（逐项点击验证，全部通过）

### 2.1 壳层
- **窄屏 BottomTabs**：五 tab「语音 / 直播 / 主页（居中凸起）/ 帖子 / 桌游」，选中态正确，各 tab 跳转正常
- **窄屏顶栏**：左「个人主页」入口、中「全局搜索」胶囊入口、右「更多」菜单（个人主页 / 我的收藏 / 退出登录，点击跳转正确）

- **宽屏 TopNav**：爱（个人主页）/ 主页 / 语音 / 直播 / 帖子 / 桌游 / 消息（未读徽标），指示条/选中态正确

### 2.2 主页 / 群聊

- **群聊天**：空态「还没有消息」+ 输入框 + 发送（输入后发送按钮启用，发送动作正常）
- **群内场景**：语音/直播/桌游空态 + 对应 FAB（创建群内语音房/群内开播/创建群内桌游室）；帖子 tab = 群内 feed（`scope=group:<id>` 正确传参）+ 底部发布框（FAB 按设计隐藏）
- **群信息**：点中央群头像 → `/group/g1/info`（群名/公告/人数/创建时间/编辑群资料/成员/管理区）

### 2.3 语音
- **大厅卡片**：来源标识（公开/好友）+ 名称 + 人数 + 「我在其中」标签；窄屏 2 列（165.6px×2）

### 2.4 直播
- **大厅卡片**：封面占位（16:9 渐变 + 状态徽章「直播中/未开播」+ 爱莉角标）+ 主播名（无数据回退「未知主播」）+ 来源；窄屏 2 列（179.6px×2）

- **直播间（宽屏）**：左侧 240px 封面侧栏（封面 72px + 标题横排、当前项高亮 + 直播红点）+ 返回键在侧栏顶部 + 收起按钮；**收起后整个收成一个浮动按钮**（含返回 + 展开，不占布局）再展开恢复；点封面切换 → `/live/:id` 高亮

### 2.5 帖子

### 3.4 测试环境限制（真实环境需后端/基础设施验证）

- **WebSocket**：chat / presence / live / voice 全部连接失败（preview 无后端）——实时消息、在线状态、弹幕推送、语音成员状态**无法在本次验证**
- **LiveKit 语音**：REST join 成功但 `ws_url` 无效导致媒体连接挂起（mock 环境）；**真实环境依赖 LiveKit 服务**。错误路径（503）已验证正常
- **HLS 播放**：mock 的 hls_url 无效时播放器报加载失败但不崩溃（容错正常）；真实播放需后端推流
- **Google Fonts**：外网字体 404（网络限制），页面回退默认字体
- **登录 / 注册页**：mock 自动注入会话 token 无法进入未登录态，本次未测（需真实登出态）

## 四、结论

1. **全部核心功能可用**：导航、主页/群聊、语音/直播/帖子的浏览与创建、消息/私聊、申请审批、搜索、个人、收藏，窄屏与宽屏两形态均正常渲染、无崩溃白屏。
2. **优先建议修复**：#1 语音「我在其中」按钮文案、#2 搜索无结果空态、#3 审批失败无提示（后两项为 UX 完善项）。
3. **建议跟进**：#5 直播卡片主播名数据源（后端列表带昵称或确保 users/search 可命中所有主播）。
4. **需真实环境回归**：WS 实时链路、LiveKit 语音进房与通话、HLS 直播播放、登录/注册。
