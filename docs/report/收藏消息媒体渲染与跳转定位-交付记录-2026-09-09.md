## 2. 关键设计决策

- **单媒体只返回 media_id，mixed 的 segments 后端展开**：单媒体消息前端 `MediaContent` 按 WS 帧同契约（media_id → `fetchMediaDescriptor` 补拉）渲染，后端改动最小；mixed 消息的段结构前端无法从 media_id 重建，必须后端 `expand_segments` 展开（含媒体段完整 descriptor）。
- **媒体本体独立于跳转按钮**：`<button>` 不能嵌套 `<button>`（无效 HTML），且媒体自带查看/播放/下载交互——点击媒体不触发跳转，点击头部/文本区域跳转。
- **参数读取放路由页（Router 内）经 prop 传入**：`PrivateChatPane` 被测试直接渲染（无 Router 上下文），直接用 `useSearchParams` 会崩；沿用项目 `NavigateBridge` 的「无 Router 上下文子组件」模式，`PrivateChatPage` 读参数构造 `externalJump` 传 prop。
- **子群匹配的两种 null 语义**：MessageList 的 `subgroupId` prop 为 undefined（私聊/无过滤）与 `externalJump.subgroupId` 为 null（默认组消息）必须区分，否则私聊跳转被误拦。

- **前端**：`FavoriteTargetType` 移除 `"group"`；收藏页 `FILTERS` 移除「群」分类（选项卡同步消失）；`openTarget` 移除 group case；`FavoriteResultCard` 移除 group 分支（`GroupResultCard` 保留导出，搜索页群聊结果仍用）。
