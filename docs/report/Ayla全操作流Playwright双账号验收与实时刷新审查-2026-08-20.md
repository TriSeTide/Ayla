## 1. 执行摘要

本轮覆盖了登录/注册、一级导航、主页、群聊、群信息、群内聊天、语音、直播、帖子、桌游、消息中心、私聊、搜索、个人页、我的帖子、收藏，以及双账号入群申请、审批、群消息、群内帖子、群内语音房和实时通知。

### 结论

- **核心页面可达、主要表单和基础 CRUD 可用**：两个账号均能注册并进入应用；主账号创建群、直播间、帖子、桌游室和语音房成功；成员账号申请入群、主账号在认证消息中同意成功。
- **双账号群消息实时链路通过**：成员发送群消息后，主账号打开群聊天时能看到成员昵称和消息正文；认证消息审批项在主账号点击同意后立即从认证消息列表移除。
- **双账号群内语音房创建实时链路通过**：主账号创建「双账号实时语音房」后，成员账号已经停留在群内语音页，页面无需刷新即出现该房间。
- **双账号语音媒体/成员状态本轮未通过**：两个窗口均显示「同步成员中…」「状态同步离线」或 0 人，WebSocket/LiveKit 状态未形成可验收的双向成员证据；应视为基础设施/连接链路待修复，而非 UI 已通过。
- **确认存在的高优先级问题**：群内和群外帖子列表均未稳定实时更新；群内/群外语音创建成功后创建弹窗不自动关闭；直播「只看在播」勾选后仍显示未开播/已结束条目；搜索页在审批完成后仍显示旧的「申请入群」状态。
- **视觉/响应式问题**：窄屏直播控制台和直播观看页的 BottomTabs 被内容推到视口下方；收藏分类在窄屏横向溢出，「群」标签初始位于 375px 视口外；群内语音房列表出现同一频道重复卡片并产生 React duplicate key 警告。

## 6. 实时刷新/WebSocket 审查

### 6.1 已有且本轮观察到有效的链路

`ws/chat.ts` 已实现以下分发：

- `group.created` / `group.joined` → `chat.upsertConversation`
- `voice.channel.created/deleted` → voice store `upsertChannel/removeChannel`
- `live.channel.created/status.changed/deleted` → live store 更新
- `post.created/deleted` → posts store 更新
- `boardgame.room.created/deleted` → boardgame store 更新
- `group.request.new/resolved`、邀请、成员离开 → 认证消息/通知 store

本轮实证：

1. 主账号同意成员入群后，主账号认证消息列表立即清空。
2. 主账号创建群内语音房后，成员账号已打开的群内语音页立即出现房间。
3. 群聊天消息通过接口/WS 能在另一账号群页呈现。

### 6.2 代码上存在但页面没有消费的链路

**群内和群外帖子都是确定缺口。** `Ayla/web/src/pages/group/GroupPosts.tsx` 使用本地 `posts` 状态，并只在 `useEffect` 中执行一次 `listPosts`。虽然 `ws/chat.ts` 会将 `post.created` 写入 `usePostsStore`，GroupPosts 没有订阅该 store，因此另一个账号创建帖子不会让已打开页面重渲染。`PostsHubPage` 虽然订阅 `usePostsStore`，但本轮双账号实测群外 `/posts` 也没有稳定出现新帖子，需要继续核对用户级/全局 feed 广播、事件 payload 和 store 合并条件。

建议：

1. GroupPosts 直接订阅 `usePostsStore` 的按群投影，或建立 `useGroupPostsStore`，保持群过滤和分页游标；PostsHub 保持全局 feed selector 并补齐事件后的分页状态处理。
2. `post.created`/`post.deleted` 事件中保留 allowed group 信息和全局 feed 所需字段，确保多群可见帖子只进入授权群的投影。
3. 群内外列表收到事件时做 ID 幂等合并，避免创建回调、REST 返回、WS 推送三路重复。

### 6.3 需要优先补齐热刷新/对账的功能

| 功能 | 当前判断 | 推荐机制 |
|---|---|---|
| 群内/群外帖子列表 | 已复现不实时更新 | `post.created/deleted` + 群投影/全局 feed store；断线后按游标对账 |
| 直播大厅「只看在播」 | 当前过滤逻辑不生效 | 本地过滤 + 后端 `only_live` 查询；`status.changed` 更新卡片徽章 |
| 搜索入群结果 | 审批后旧状态不变 | `group.joined/request.resolved` 失效搜索结果，或短 TTL 重新查询 |
| 语音/直播/桌游大厅 | store 有事件能力，页面需确认订阅 | 统一 selector 订阅 store，REST 仅作初始快照和重连对账 |
