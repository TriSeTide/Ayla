## 六、补充的完整操作流结果

### 6.1 群成员管理实际操作

重新申请并审批成员后，群主在群信息页完成：

- 点击「设为管理员」：成功，成员角色显示为「管理员」，按钮变为「撤销管理员」。
- 点击「转让群主」并输入真实成员 ID：成功，原群主变为管理员，新账号显示「我 / 群主」。
- 原群主作为管理员打开群信息：能看到「撤销管理员」「移除」等管理控件。
- 新群主点击「移除」：请求返回 204，成员数从 2 变为 1，成员被移除。

有效转让请求返回 200；无效成员 ID 的转让请求返回 404，页面显示「目标成员不存在」。

### 6.2 群内帖子与默认可见范围

必须从群主页点击「帖子」才能稳定进入 /group/22/posts。群内帖子页显示底部发帖输入框，「指定群可见」默认选中，当前群复选框已勾选。该默认值验收通过。

### 6.3 群内语音与默认可见范围

从群主页点击「语音」后，点击「创建群内语音房」，弹窗显示「指定群可见」默认选中，当前群复选框已勾选；搜索群输入框存在。该默认值验收通过。

### 6.4 个人帖子与编辑

当前账号在 /posts 发布「操作流验收帖子」，成功进入 /posts/7；详情页有「编辑」按钮。点击编辑后修改正文并点击「重新发布」，接口返回 200，页面显示第二版内容。随后 /posts/mine 能稳定显示该帖子，个人帖子列表和编辑流程通过。
