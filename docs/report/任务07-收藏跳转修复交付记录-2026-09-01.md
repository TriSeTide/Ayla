## 0. 修复后补记：宽屏收藏选项卡垂直截断（2026-09-01 用户实测发现，已修复）

- **现象**：xixi 账号（xixi/xixi-pass-2026）登录后，宽屏收藏页七个筛选标签只剩底部约 8px 细边、文字完全不可见（视觉"截断"）。
- **根因**：`.favorites-filters` 设了 `overflow-x: auto`（横向滚动需要）→ 按 CSS 规范，overflow 非 visible 时 flex item 的 `min-height: auto` 计算为 0 → `.favorites-page`（flex column，`height:100%`）高度不足时筛选条被 flex 压缩到只剩 `padding-bottom`（8px），tab 内容被垂直裁切。顶栏因 overflow visible 受 min-height:auto 保护未被压缩，故只有筛选条塌陷。
- **修复**：`.favorites-filters` 加 `flex-shrink: 0`（禁止参与 flex 压缩）。
- **验证**（xixi 账号，`https://192.168.1.2:5173` 家里网络）：宽屏 1908 下 filters 高度 8px→44px、tab 36px 完整、7 标签全部可见（截图 `xixi-favorites-fixed-1908.png` 视觉复核通过）；窄屏 390 回归：filters 54px 正常、页面无横向溢出、筛选条可横向滚动且群 tab 滚动后 right=342<390 可达。
- **教训**：此前验收只测了 `scrollWidth/clientWidth`（宽度），未检查 `clientHeight`——filters `ch=8` 当时已是异常信号（内容 44px 被裁）但被忽略；布局验收必须同时核对宽高两个维度。
