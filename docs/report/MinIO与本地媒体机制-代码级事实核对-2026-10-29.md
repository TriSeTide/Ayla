## 0. 一页结论

| 问题 | 答案（代码级） |
|---|---|
| 什么东西进 MinIO | **所有用户媒体字节**：图片/表情/语音/视频/文件的原件 + 缩略图 + 波形。key = `media/{kind}/{media_id}/{original\|thumbnail\|waveform}`（`apps/media/storage.py:367-376`） |
| 什么东西留在本地（后端） | **没有本地媒体库**。`MEDIA_ROOT/MEDIA_URL` 未定义、`FileField` 0 命中；只有 `MEDIA_TMP_DIR` 的 3 处 `TemporaryFile`（用完即删，`settings.py:241-244`、`views.py:113`、`services.py:492/872/875`） |
| 什么东西通过本地文件看 | **只有 Flutter 客户端**（漫游缓存）：`Image.file` / media_kit `open(本地路径)`。**Web 端没有任何媒体本地持久化**（IndexedDB/CacheStorage/OPFS/ServiceWorker 全 0 命中） |
| 什么东西通过 MinIO 看 | **几乎所有媒体数据面**：`:sign` 签预签名 GET → 前端改写成同源 `/minio` → nginx 固定 Host → 浏览器/客户端直连 MinIO。**后端只签不转发** |
| 什么走了后端 /content | **语音**（web + Flutter 都是 `/api/v1/media/{id}/content` + Bearer）；以及 Flutter 文件保存读字节 |
| 什么东西看了会存本地 | Flutter：图片**看见存 thumb**、点开查看器存 original；语音**点击播放才存**；视频**点开查看器才存**（气泡不存）；**文件永不自动存**。Web：**什么都不存**（只有内存级签名 URL 缓存 + 浏览器 HTTP 缓存） |
| 什么在 MinIO 会过期 | 聊天媒体：图片 7 天删原图留缩略图 → 30 天全删；语音/文件/视频 7 天全删；**emoji 永不过期**；被 A1–A7 资产引用的一律永久 |
| **过期真的在跑吗** | **没有**。`cleanup_media --expire-chat-media` 在仓库与生产**零调度、零执行痕迹**；线上 51 条媒体记录两个过期字段 **100% NULL** |

## 1. 两条数据面：谁走 MinIO，谁走 Django

### 1.1 链路 A：预签名直连 MinIO（≈全部媒体）

```
浏览器/客户端 --POST /api/v1/media/{id}:sign--> Django（鉴权 + 签 URL，TTL 600s）
             <-- { url, expires_at }
浏览器/客户端 --GET <S3_ENDPOINT>/... （前端改写为同源 /minio/...）--> nginx --固定 Host 127.0.0.1:9000--> MinIO
```

- 签发：`apps/media/views.py:250-297`；TTL `MEDIA_VIEW_URL_TTL_SECONDS = 600`（`apps/media/services.py:36`）。
- host 改写：web `Ayla/web/src/api/media.ts:337-339` `toSameOriginMinio()`；Flutter `Ayla/flutter/lib/core/media/media_signer.dart:189-203`（返回**绝对** `<apiBase>/minio/...`）。
- 代理：生产 nginx `location /minio/`（`proxy_pass ...:9000/` + **`proxy_set_header Host 127.0.0.1:9000`** + `proxy_buffering off` + `client_max_body_size 0`）。
  dev 由 Vite `/minio` proxy 的 `changeOrigin` 等价实现（`Ayla/web/vite.config.ts:38-42`）。
- 为什么必须固定 Host：预签名 URL 的 `X-Amz-SignedHeaders=host`（线上日志实测），host 是签名的一部分。
- **Range 由 MinIO 原生处理**：`<video preload=metadata>` / 拖动 seek 只拉所需字节，播放流量不进 Django。

### 1.2 链路 B：后端流式 `/api/v1/media/{id}/content`

- 端点 `apps/media/views.py:315-410`：双通道鉴权（Bearer 或 HMAC 票据），Range→206 / 无 Range→分块 200，
  `ETag`、`Cache-Control: private, max-age=3600`（派生资源 7200，`views.py:424`）。
- **对象已删时返回 404 `media_content_unavailable`，不是 410**（`views.py:344-351`）——410 只出现在 `:sign`。
- 真实消费者只有：**语音播放**（web `MediaContent.tsx:528-533` `apiRequestBlob`+Bearer→`createObjectURL`；Flutter `core/media/audio_playback.dart:104-115`）
  与 **Flutter 文件保存读字节**（`core/media/media_download.dart:50-74`）。
- 其余组件里出现的 `/api/v1/media/{id}/content` 只是**id 载体**：`ResourceImage.extractMediaId()` 抠出 id 后**又转回链路 A**（`ResourceImage.tsx:48-58,155-158`）。

### 1.3 各媒体的实际链路

| 媒体 | web | Flutter | 数据面 |
|---|---|---|---|
| 图片/表情气泡 | thumb（GIF/表情走原图） | thumb | A |
| 图片查看器 | original | original | A |
| 图片保存 | `<a download>` original | `FilePicker.saveFile` | A（web）/ B（Flutter 读字节） |
| 视频气泡 | 海报 thumb / 无海报签 original | 同 | A |
| 视频播放 | original（查看器） | original | A |
| 语音 | **B**（全量 blob） | **B**（Bearer 流） | B |
| 文件下载 | `<a download>`（签 original） | 保存对话框（读 B 字节） | A / B |
| 头像/封面/帖子图 | ResourceImage→A | AylaResourceImage→A | A |

## 3. 上传与 tmp 生命周期

**三步**（`views.py:48-179`、`services.py:373-461`）：
1. `POST /media/uploads` → 策略校验 + 建会话（TTL `MEDIA_TMP_TTL_SECONDS=600`）+ 返回 `presigned_url`（TTL=max(600,会话剩余)）。
2. 浏览器 **XHR PUT 直打 `/minio`**（`media.ts:354-390`，只带 Content-Type，**绝不带 Authorization**，否则破签）。
3. `POST /media/uploads/{id}:complete` → 只做 `stat`+64B 魔数嗅探 + 服务端 `copy`（字节不进 Django）→ 去重(content_hash+kind) → 建 MediaObject → 派生 → `READY`。

**tmp 的 4 条删除路径 / 3 条残留路径**：

| 会删 | 位置 |
|---|---|
| complete 成功后删 tmp | `services.py:445-449` |
| 用户取消 DELETE | `views.py:135-145` → `services.py:341-350` |
| faststart 完成 | `services.py:904-905` |
| cleanup 扫过期 pending 会话 | `cleanup_media.py:119-128` |

| 残留（代码可证） | 后果 |
|---|---|
| **去重命中不删 tmp**（`services.py:422-427`，注释称"由 cleanup 兜底"） | 该会话是 completed ⇒ cleanup 只扫 pending ⇒ **永久残留**（线上 16/18 个存活 tmp 属此类） |
| complete 失败（size/mime/嗅探）直接 raise | tmp 无清理 |
| 惰性过期只把会话置 EXPIRED（`services.py:352-361`），不删 tmp | 状态变了 ⇒ cleanup 的 pending 过滤再也捞不到 |
| `tmp/faststart-*` 不属于任何会话 | 中断即残留 |

**关键缺口**：后端**从不 list 桶**（`list_objects*` 全仓 0 命中，`storage.py` 也无 list 接口）⇒ 孤儿 tmp 没有任何兜底扫描路径。

## 4. 过期机制（`cleanup_media --expire-chat-media`）

### 4.1 算法（`cleanup_media.py:141-233`）

```
候选 = MediaObject(created_at < now - min(TTL), status=READY, expired_at IS NULL)   # :162-168，全量 list
保护 = A1..A7 全量扫描（每次运行重扫）                                              # :55-90
逐条：
  命中保护        → skip
  kind == emoji   → skip（显式，:178-183）
  kind == image   → 若 age ≥ FULL(30d)：删 original+thumb+waveform，置 expired_at（并补 original_expired_at）
                    否则若 age ≥ ORIGINAL(7d)：只删 original，置 original_expired_at
  voice/file/video→ 若 age ≥ 7d：删全部对象，置 expired_at
```

- 默认 TTL（`settings.py:232-236`）：image 7/30 天；voice/file/video 各 7 天；`<=0` 表示禁用。
- **DB 记录永不删行**，只打时间戳（`models.py:71-76`）。
- 幂等：阶段 1 有 `original_expired_at is None` 闸门；阶段 2/单级靠 `expired_at` 退出候选；`--no-delete` 不删也不标记。

### 4.2 保护集合 A1–A7（代码位置）

| # | 引用 | 扫描代码 |
|---|---|---|
| A1 | `PostImage.media` | `cleanup_media.py:76` |
| A2 | `EmojiItem.media` | `:77` |
| A3 | `Comment.media_id` | `:79-81`（会混入字面 `"None"`：`exclude(media_id="")` 不排除 NULL 行） |
| A4 | `Comment.images` JSON | `:82-85` |
| A5 | `User.avatar` | `:87`（正则 `/api/v1/media/([^/]+)/content`，`:37`） |
| A6 | `Conversation.avatar` | `:88` |
| A7 | `LiveChannel.cover` | `:89` |

**不保护（可过期）**：E1 `Message.media_id`、E2 `Message.segments`、E3 `Danmaku.media_id`、E4 `VoiceChatMessage.media_id`。

### 4.3 入口闸门：资产引用必须"原图完好"（Q2 已落地）

6 处资产写入点均校验 `original_expired_at is None and expired_at is None`，违约返回 `media_expired`：
`emoji/services.py:127-128`、`posts/serializers.py:241-242`（发帖）、`:300-301`（编辑）、`:357-358`（评论）、
`live/views.py:104-105`（封面）、`media/services.py:697-698`（头像 A5/A6）。

### 4.4 前端的过期语义（唯一判定源 = `:sign` 的 HTTP 状态码）

| 后端返回 | web 行为 | Flutter 行为 |
|---|---|---|
| original → 410 `original_expired` | 自动改签 thumb，显示「原图已过期」角标（`media.ts:84-93`、`ResourceImage.tsx:225-229`） | 同（`media_signer.dart:147-163`） |
| thumb → 410 `media_expired` | `MediaExpiredError` → 「已过期」灰底占位，不重试 | 同（`media_signer.dart:141-146`） |
| thumb → 404 `thumbnail_not_ready` | 按完全过期处理（`media.ts:96-98`） | 同（`media_signer.dart:167-168`）—— ⚠️ 缩略图未生成会被误显示为已过期 |
| `/content` 对象缺失 | 语音：404/410 → 「已过期」（`MediaContent.tsx:554-555`） | 同 |

**全仓没有任何地方消费 `descriptor.status` 来驱动过期 UI** —— 一律以服务端响应为准。

### 4.5 ⚠️ 调度事实：这套机制**从未被触发**

- 代码：`crontab|celery|beat|systemd|APScheduler` 在 `Ayla/backend` **0 命中**；deploy 里 cron 只有 acme 续签与 frp keepalive；Dockerfile CMD 只有 migrate+collectstatic+daphne。
- 生产：用户 crontab 7 条**无** `cleanup_media`（唯一 `manage.py` 定时任务是 `voice_reap_stale_members`）；system/user systemd 无相关 timer；容器内无 cron；`docker logs | grep '\[media\]'` = **0**。
- DB 佐证：`media_objects` 51 行**全部 ready**、两个过期字段 **100% NULL**；13 个 pending 上传会话**全部早已过期**（跑过就会被置 expired）。
- 生产 `.env` **没有任何 `MEDIA_CHAT_*_TTL_DAYS`** ⇒ 生效值 = 代码默认 7/30/7/7/7。
- 线上镜像中 `cleanup_media.py`/`storage.py`/`services.py` 与本机工作区 **sha256 逐字节相同** ⇒ **缺的是调度，不是代码**。

## 5. 本地媒体机制（三端对比）

### 5.1 Web：**无本地持久化**

| 能力 | 结果 |
|---|---|
| IndexedDB / CacheStorage / ServiceWorker / OPFS / FileSystemAccess | 0 命中 |
| `localStorage` | 18 处，全非媒体（首页布局、最近群、搜索历史） |
| 媒体字节 | **不落盘**。刷新/离线后必须重新签发 + 重新下载 |

仅有的内存级复用：`signedUrlCache`（签名 URL，非字节，`media.ts:43`）、`warmVideoPool`（≤4 个 detached `<video>`，`media.ts:141-142`）、`mergeMedia`（descriptor 合并）。
浏览器 HTTP 缓存：`/content` 显式 `private, max-age=3600`；`/minio` 响应缓存头**只来自对象元数据**（nginx 不加任何 header，正式媒体对象无 Cache-Control ⇒ 每次重签即回源）。

### 5.2 Flutter：**漫游缓存（disk）**

**根**（`media_cache_paths.dart:184-221`）：Windows `<exe>/data/media-cache`（不可写则降级 `ApplicationSupport/media-cache`，`degraded=true`）；Android/iOS `ApplicationSupport/media-cache`。
**布局**：`<kind>/<media_id 前 2 位>/<media_id>[.thumb].<ext>`；original 与 thumb **物理分开、互不覆盖**。
**写**：`.tmp` → flush → rename 原子写（`media_cache.dart:540-560`）；并发 `_inflight` 键 = `kind|id|variant`。
**容量**：**无上限、无 LRU、无 TTL**（`media_cache.dart:14-15`）；`stats()`/`evict()` **生产零入口**，只有测试调用。
**读**：命中即返回，**连 `:sign` 都不发**（`media_cache.dart:615-621`）⇒ 「本地有就一直能看」，云端 410 也看不到。
**跨账号**：目录无 user_id 段 ⇒ 同一台机器 A 号看过的图 B 号也能命中；**登出/401 不清磁盘缓存**。

**落盘时机（代码为准）**：

| kind | 触发 | 存哪种 | 证据 |
|---|---|---|---|
| 图片（气泡） | 渲染看见 | **thumb** | `widgets/base/resource_image.dart:391-401` |
| 图片（查看器） | 点开大图 | **original** | `widgets/chat/image_viewer.dart:1353-1362` |
| emoji 消息 | **不缓存**（`cacheable: !isEmoji`） | — | `widgets/chat/media_content.dart:587` |
| 语音 | **点击播放**（`_toggle`→`_ensureEngine`） | original | `media_content.dart:1326-1334` |
| 视频（气泡） | **不落盘**（只签 URL 取首帧） | — | `media_content.dart:741-755` |
| 视频（查看器） | 点开查看器即存（无需按播放键） | original | `image_viewer.dart:1043` + `widgets/base/media_interaction.dart:125-134` |
| 文件 | **永不自动存**，只走「保存」按钮 | — | `media_content.dart:1736-1750`、`core/media/media_download.dart:32-47` |

**「通过本地文件看」的实现**：`Image.file`（`resource_image.dart:568-610`、`image_viewer.dart:1385-1403`）；音频 `engine.open(cached.path)`（media_kit）；视频 `_videoSrc = cached.path` → media_kit（Windows 可用；**Android/iOS 用 `VideoPlayerController.networkUrl` 传本地路径，疑似失效，未证实**）。
**启动预热**：`main.dart:243-248` `unawaited(ensureReady())`（含一次性 `.tmp` 清理）。

### 5.3 Elysia（主体）侧

- Ayla 桥接只传 `message.media_id` 字符串（`apps/elysia_bridge/services.py:874`），**不搬运媒体字节**；
  Elysium 的 `plugins/ayla_adapter` 无任何媒体逻辑（全文件 grep media/upload/image/voice = 0）。
- Elysium 自己的 `data/media_cache` 是**表情素材库**（`plugins/emoji/sender/service.py:145-147`），与 Ayla 媒体域无关。
- 线上该目录 1.4 GB（images 1.1G + emojis 233M，2026-07-18 后停更），属另一议题的占盘项。

## 6. 「保存到本地」到底发生了什么

| 端 | 行为 | 证据 |
|---|---|---|
| web 图片/视频 | `:sign` 拿 original → `<a download href=同源签名URL>` → 浏览器原生流式写盘（零 blob、零 createObjectURL）。**同源是 `download` 属性生效的前提** | `ImageViewer.tsx:92-101` |
| web 文件消息 | 同上，`download={name}`；过期时降级为不可点图标 | `MediaContent.tsx:765-772` |
| Flutter 图片/视频 | 缓存命中→直接读本地；否则 `fetchAndStore`/裸签名 Dio → `FilePicker.saveFile`（系统对话框/SAF） | `image_viewer.dart:258-319` |
| Flutter 文件 | 缓存命中→读本地；否则 `/content`+Bearer 读字节 → `FilePicker.saveFile` | `media_download.dart:32-74` |

固定落点：web = 浏览器默认下载目录；Flutter = 用户在选择框里指定的位置（不写漫游缓存）。

## 8. 缺口清单（按影响排序）

### P0 —— 存储回收是断的

1. **过期命令零调度**（§4.5）：7/30 天机制是死代码路径。要么补 cron（可照抄现有 `voice_reap_stale_members` 那条），要么明确"永不过期"并改文档。
2. **版本化让所有删除失效**：`storage.delete()` 只写 delete marker ⇒ 即使跑了 cleanup，**磁盘也不会释放**。要么 `mc version suspend`（会丢历史版本，需用户裁决），要么在 delete 时带 `VersionId` 做彻底删除。
3. **tmp 泄漏第二通道**：去重命中不删 tmp（`services.py:422-427`）⇒ completed 会话的 tmp 永久残留（线上 16/18 个）。修法：dedup 分支也删 tmp；或给 cleanup 增加「completed 会话 + tmp 仍存在」分支。

### P1 —— 语义/契约不一致

4. `:sign` 的 404 `thumbnail_not_ready` 被两端当成「完全过期」（`media.ts:96-98`、`media_signer.dart:167-168`）⇒ 缩略图尚未生成时会误显示"已过期"。
5. `/content` 对已删对象返回 **404** 而非 410（`views.py:344-351`），与 `:sign` 不一致；文档只说 410。
6. `status` 卡在 `processing` 的媒体**永不进入过期流程**（候选硬要求 `READY`）。
7. `MediaDeleteView` 只删 original+thumbnail，**不删 waveform**（`views.py:207-211`）。
8. 保护集合混入字面 `"None"`（`cleanup_media.py:79-81`）；`can_access_media` 的 A5/A7 用 `__contains` 子串而保护集合用正则，口径不同。
9. web 语音波形图签的是 original（后端无 waveform 变体）⇒ 波形很可能显示不出来（**未实测**）；`VoiceRoomBody.tsx:194`/`DanmakuList.tsx:73` 缩略图漏传 `variant="thumb"`。

### P2 —— 客户端

10. Flutter `MediaSigner.detach()` **生产零调用**（注释要求登出必须调）⇒ 旧会话签名 URL 跨账号残留内存（磁盘缓存是有意共享的，不受影响）。
11. 无任何「清理缓存」入口（`stats`/`evict` 仅测试）：磁盘只增不减。
12. 移动端视频本地播放用 `VideoPlayerController.networkUrl` 传本地路径（疑似失效，未证实）；查看器视频 `_buildPlayer` 仍是占位实现。
13. `MEDIA_THUMB_MAX` 死配置；`put_session_binary` 死代码。
