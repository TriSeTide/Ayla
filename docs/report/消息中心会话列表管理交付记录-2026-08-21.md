# Ayla 消息中心会话列表管理交付记录（M5）

> 日期：2026-08-21
> 需求：`/messages` 私信列表添加管理功能（删除、置顶）；在线状态移到名字后面，原预览位置改为显示最新一条消息。

## 一、需求与决策

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 删除语义 | 软删除（仅隐藏本人列表，不删消息） | 用户确认；数据不丢，对方再发消息/重新联系自动恢复 |
| 管理交互 | 会话行右侧 ⋯ 更多按钮 → 弹出菜单（置顶/取消置顶、删除） | 用户确认；宽窄屏通用，键盘可达 |
| 最新消息来源 | 后端会话列表新增 `last_message` 摘要字段；WS `message.new` 实时刷新预览 | 列表不依赖每次刷新，新消息即时可见 |
| 置顶存储 | `ConversationMember.is_pinned`（成员各自视图） | 置顶是个人偏好，不能放 Conversation 全局共享 |
| 隐藏存储 | `ConversationMember.hidden`（成员各自视图） | 同上；发消息时自动清除全体成员 hidden |

## 二·扩展、群聊会话管理 + 群"新内容"实时排序（同日追加）

### 群聊 ⋯ 菜单（用户纠正后定稿）

- **群聊不提供删除**（用户原话「群聊不要加删除按钮…只需要置顶按钮就行」）；群卡片/群列表右下角 ⋯ 仅「置顶/取消置顶」
- `ConversationMoreMenu`（新共享组件 `components/chat/ConversationMoreMenu.tsx`）：会话列表/群卡片/群列表共用，`showDelete` 开关（私信 true、群聊 false）
- `ConversationList` 重构复用该组件
- **置顶小图标**：45° 左倾粉色 pin（`--pink-500`，`transform: rotate(-45deg)`），无背景圆——群卡片左上角（`.group-card-pin`，卡片外绝对定位不占空间）、群列表标题前（`.group-list-pin-icon`）、宽屏 ServerRail 头像左上角（`.server-item-pin`）

### 宽屏 ServerRail 悬停展开置顶面板

- 鼠标悬停群头像自动展开面板（群名 + 置顶/取消置顶），`components/chat/groupActivity` 无关；`layout/ServerRail.tsx` 内实现
- **布局坑**（已解决）：`.server-rail-list` 的 `overflow-y:auto` 隐式 `overflow-x` 会裁剪/滚动溢出的面板；rail 的 `backdrop-filter` 会为 `fixed` 后代创建包含块（相对于 rail 而非视口）。解法：面板 `position:absolute` + `getBoundingClientRect` 相对 rail 坐标 + rail `z-index:20` 提升层叠压过 ChannelSidebar

### 群"新内容"WS 实时排序与事件描述（多轮用户纠正后定稿）

- 新工具 `components/home/groupActivity.ts`：
  - `useGroupPresenceMap`（**角标/存在性**）：群内当前有直播在播 / 语音房 / 桌游房，与排序无关；
  - `useGroupActivityMap`（**排序/事件性**）：订阅 live/voice/boardgame/**posts** 四 store，按群归属/白名单投影窗口内事件，合并最后一条消息事件，输出 `{lastNewAt, lastEvent}`；
  - `sortGroupsByActivity`（置顶 > 有新内容按最近事件时间新→旧 > 无内容稳定）+ `hasGroupActivity`；`NEW_CONTENT_WINDOW_MS` = 24h
- **"新内容"= 窗口内事件，五类**：新消息（**窗口内最后一条消息，含自己的，不依赖已读**）、新开播（直播 `started_at` 窗口内）、新语音房被创建、新桌游房被创建、**新帖**（posts store `created_at` 窗口内）；超出窗口的"在播/在房"不算新不排前
- **窄屏列表布局 sub 显示具体事件描述**（替代"新内容"三字）：
  - 新消息：`发送者：内容`（如「小樱：今晚一起吃饭吗」）
  - 新开播：`主播 开播了 标题`；新语音房：`xx 创建了语音房 房名`；新桌游房：`xx 创建了桌游房 房名`；新帖：`xx 发了新帖 标题`
  - 无新内容显示「N 人」；事件文本用 `--pink-500` 强调（`.group-list-sub.is-new`）
- 接入：HomePage（排序 + 卡片存在性角标 + 列表事件描述）；GroupPage → ServerRail（groups 传排序结果）
- **WS 实时**：live/voice/boardgame/posts 四 store 由 ChatWS 事件维护（含 `post.created/deleted` 拉完整帖子 upsert/移除 posts store）+ 登录预加载，store 变化即重渲染 → 排序/事件描述即时刷新
- 语音房事件需要创建者名：后端 `voice/serializers.py` 补 `owner_nickname`（`web/src/api/types.ts` 同步字段）
- 测试：`vitest/group-activity.test.ts`（判定+稳定+按时间降序+置顶组合+消息/新帖事件）

## 四、边界与回滚

- 软删除不触碰消息数据，回滚只需删除迁移 0007 或重新 `migrate` 反向
- 隐藏会话收到新消息自动恢复（后端事务内 + 前端 WS 刷新双保险）；若只想手动恢复，重新发起私聊（`openPrivateConversation` 复用原会话）也会因新消息恢复
- `last_message` 为列表优化字段，无消息返回 null，前端显示「暂无消息」
- 已知既有问题（非本次引入）：Avatar 可点击头像渲染为 button 嵌套在会话行 button 内，React 有 validateDOMNesting 警告，浏览器行为正常；如需彻底修复需把行容器改为非 button 语义，属后续重构项
