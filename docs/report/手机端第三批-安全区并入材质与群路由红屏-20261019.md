## 1. 正确形态与实现

```text
❌ 割裂（裸留白）                ✅ 连成一片（材质内部占位）
┌──────────────┐                ┌──────────────┐
│ 1:03  5G  ▮ │ ← 极光底色      │ 1:03  5G  ▮ │ ← 同一块磨砂底
├──────────────┤                │ ← 群聊       │
│ ← 群聊       │ ← 玻璃顶栏      └──────────────┘
└──────────────┘
```

### 新增 `lib/widgets/base/safe_area.dart`

| 导出 | 用途 |
|---|---|
| `AylaTopInsetGap()` | 放进**头部材质内部**的第一个 child（高 = `viewPadding.top`，为 0 时零产出） |
| `aylaTopInset(context)` | 卡片式页面直接加进滚动容器顶部内距 |

```dart
// 通栏玻璃条（头部贴屏幕顶边）
AylaGlassSurface(
  child: Column(mainAxisSize: MainAxisSize.min, children: [
    const AylaTopInsetGap(),
    SizedBox(height: 56, child: 头部内容),
  ]),
)

// 卡片式滚动页（卡片与顶边不相接）
SingleChildScrollView(
  padding: EdgeInsets.fromLTRB(sp3, sp3 + aylaTopInset(context), sp3, sp3),
)
```

### 选型判据

| 页面形态 | 做法 |
|---|---|
| 头部是**通栏玻璃条**（贴屏幕顶边） | `AylaTopInsetGap()` 放进材质内部 |
| 内容是**卡片式滚动**（卡片与顶边不相接） | `aylaTopInset()` 加进滚动容器内距 |
| 外层 `SizedBox` 裸留白 | **永远不要** |

## 2. 红屏崩溃：群路由不能用 `push`

### 现象

用户实拍：搜索结果里加入群聊 → 整屏红色错误页

```text
'package:flutter/src/widgets/navigator.dart': Failed assertion: line 4096 pos 18:
'!keyReservation.contains(key)': is not true.
```

### 根因

群页 5 条路由**共用同一个 `kAylaGroupShellPageKey`**（`router/app_router.dart:91`）：

```dart
final LocalKey pageKey = aylaIsGroupScene(state.uri.path)
    ? kAylaGroupShellPageKey   // ← 5 条群路由同一个 key（为了切场景不重建整页）
    : ValueKey<String>(state.uri.path);
```

第二批我把「列表 → 详情」统一改成了 `context.push`，其中包含 3 处「进群」。
同一个 Page key 被压到栈上两次 ⇒ Navigator 的 keyReservation 断言失败 ⇒ 红屏。

### 修复

回退 3 处群路由 push → `go`：

| 位置 | 场景 |
|---|---|
| `pages/home_page.dart` | 主页群卡片进群 |
| `pages/search_page.dart` ×2 | 搜索结果进群 / 加入群后跳转 |

群内的逐级返回本就由 `GroupPage` 的 `PopScope` + 场景历史栈（`_popScene`）承担，
**不依赖路由栈** ⇒ 改用 `go` 后返回行为不变。

### 纪律

> 把 `go` 改成 `push` 之前，先看该路由的 `pageBuilder` 有没有**固定 key**。
> 有固定 key 的路由族（本项目目前只有群页 5 条）**绝不能 push**。

## 5. 流程教训

1. **「唯一 owner」与「正确视觉」是两件事**：横切关注点需要统一处置，但处置的具体形态
   必须服从视觉事实（这里是「材质要连续」），不能为了统一而牺牲观感。
2. **用户说「上一版某处是对的」时，那是最高优先级的事实源** —— 直接照它改，别再自己发挥。
3. **改导航语义前先查 Page key**：共用固定 key 的路由族不能 push。
4. **同日多轮修复必须回填订正旧文档**：第二批报告里被推翻的结论已就地改写，
   避免留下两种矛盾说法。
