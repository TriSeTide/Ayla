# Auroraqua 本轮功能改动验收清单

核对日期：2026-09-08。范围为本轮 Ayla 从 `b6b14a1` 起的修改。纯颜色、圆角、阴影、位移方向等外观项已剔除；凡改变接口、权限、数据加载、缓存、请求并发、路由、输入/已读、点击/滚动、资源生命周期的改动均纳入。因布局/动画重构改动了这些实现的，也列为功能回归，不把已有业务能力冒称本次新增。

共74个验收项，原F01–F61编号保持；用户进一步要求补齐当前可达控件状态和所有可增长列表，新增F62–F74。下表“预期”是用户验收标准，**所有用户验收状态均为待验**；已有自动化结果不替代用户验收。最初60项仅只读核对代码与既有证据，随后按明确授权追加产品修复；本轮不操作正式数据或启动/重启正式服务。

提交边界：此前12个模块及其父仓库指针已逐对提交，Ayla截止`26e6e85`；用户要求新增补齐工作也按模块提交，每次同步父仓库指针，全部完成后关机。后续提交状态以最终交付记录为准，目前未推送。

优先关注F02–F03群头像权限变化、F24–F25群帖加载/未读行为变化、F34–F45语音生命周期，以及新增分页的数据完整性边界。F28最初只有静态风险依据，现已修复请求期间的实时合并并通过定向测试，不能继续表述为未修复。

并发项需要使用测试账号、第二个浏览器会话及可控的请求延迟/失败；普通限速能提高触发概率，不能保证精准卡住所需阶段。开发者工具查看请求时不要记录或复制认证头/媒体凭据。
