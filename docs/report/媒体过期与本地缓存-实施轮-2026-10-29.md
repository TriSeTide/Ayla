## 2. Flutter 落盘时机（本轮最终版）

| kind | 时机 | 存哪种 | 代码 |
|---|---|---|---|
| 图片（气泡） | 渲染看见 | thumb | `resource_image.dart` → `enqueue(variant: thumb)` |
| 图片（查看器） | 点开大图 | original | `image_viewer.dart` → `enqueue(kind: image)` |
| 语音 | **点击播放** | original | `media_content.dart` → `enqueue(kind: voice)` |
| 视频（气泡） | **不落盘** | — | `media_content.dart` |
| 视频（查看器） | 点开即存 | original | `media_interaction.dart` `AylaSignedVideo(cacheable: true)` |
| 文件 | **永不自动存** | — | 只走「保存」按钮 |

## 3. 本轮修掉的缺陷

| # | 缺陷 | 修法 |
|---|---|---|
| 1 | **手机端听不了语音**（media_kit 只有 Windows libs，移动端无 libmpv） | Android/iOS 改 just_audio（ExoPlayer/AVPlayer），桌面保留 media_kit；接口 `AylaAudioEngine` 不变 |
| 2 | **视频查看器没有播放内核**（`_buildPlayer` 是占位文案） | 接入 `AylaVodVideo`；「点开视频自动存」才真正触发 |
| 3 | 视频气泡/查看器不查本地缓存 | `AylaSignedVideo._sign` 先 lookup（布局就绪时），命中直接播本地 |
| 4 | thumb 未就绪的 404 被当「已过期」 | 仅**降级分支**里的 404 算过期；直接请求 thumb 的 404 → 可重试 |
| 5 | `/content` 与 `:sign` 过期语义不一致（404 vs 410） | 已过期统一 410 `media_expired`；未标记但对象缺失仍 404 |
| 6 | **语音波形图永远不显示**（后端无 waveform 变体） | `:sign` 新增 `variant=waveform`；web 语音条显式使用 |
| 7 | 缩略图路径漏传 `variant`（语音房 / 弹幕列表 / Flutter 语音房） | 全部补上 |
| 8 | `MediaDeleteView` 不删 waveform | 三个 key 全删 |
| 9 | 卡 `processing` 的媒体永不过期 | `MEDIA_PROCESSING_STALE_HOURS=24` 转 failed 并纳入过期 |
| 10 | 落盘意图「页面滚走/进程退出就丢」 | 持久下载队列（落盘续跑 + 最多 3 次重试） |
| 11 | `MediaSigner.detach()` 生产零调用 | 两条登出链都补上 |
| 12 | 缓存文件名扩展名按 kind 兜底（voice → .webm，实际 m4a） | 队列任务携带 `mimeType`，按真实 mime 推导扩展名 |
| 13 | descriptor 无过期投影 ⇒ 每次多一次必然 410 的 :sign | descriptor 新增 `original_expired` / `expired`，web+Flutter 直接据此渲染 |
