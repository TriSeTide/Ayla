# 群内表情包（面板 + 上传权限）功能交付记录 — 2026-09-01

> 任务来源：`.workbuddy/prompts/ayla/03-群内表情包.md`。本质不是新消息类型，仍是图片（动图）消息：点击表情包按钮弹出面板，群主/管理员默认可点加号上传群表情，群详情页群主可开关"允许普通群成员上传"，群内所有人可点击发送。

## 1. 需求本质

- **群表情包** = 关联群的表情包，对群内所有成员可见、全员可点击发送（复用现有 image/emoji 消息链路，不新增消息类型）；
- **上传权限**：默认仅群主/管理员；群详情页群主可设置"允许普通群成员上传"开关，开启后普通成员也可上传；
- **面板交互**：点击表情包按钮弹出面板（宽屏向上弹窗、窄屏向下展开、输入框上移）；面板含加号框（有权限时显示）；点击表情直接发送；
- **按钮布局**：宽屏 composer 横排（图片/文件/语音/表情包）；窄屏输入框下方四个按钮（图片/语音/表情包/文件）。

## 2. 契约

### 2.1 模型（`backend/apps/emoji/models.py` + 迁移 0002）

`EmojiPack` 新增两个字段：

- `group` FK → `chat.Conversation`（null=True）：群表情包 = group 非空、owner 为空、is_system=False；个人包/系统包 group 为空（三种形态互斥，由 services 保证）；
- `allow_member_upload` BooleanField（默认 False）：群主设置的"允许普通群成员上传"开关。

迁移：`backend/apps/emoji/migrations/0002_emojipack_group_allow_member_upload.py`（依赖 chat 0010）。
**已对开发库 MySQL（ayla）执行 `manage.py migrate emoji`（2026-09-01）**：emoji 0002 与依赖链上的 chat 0010（任务 01 poke，此前未应用）一并应用，`emoji_packs` 表已含 `group_id`/`allow_member_upload` 列。

### 2.2 接口（挂 `/api/v1/emoji/`，`backend/apps/emoji/views.py`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/emoji/groups/<conv_id>/pack/` | 群成员 | 群表情包 + `can_upload`/`can_delete`/`allow_member_upload`；包未创建返回 404（前端按空态处理） |
| PATCH | `/emoji/groups/<conv_id>/pack/` | 仅群主 | 设置 `allow_member_upload`（布尔，非布尔 400） |
| POST | `/emoji/groups/<conv_id>/pack/items/` | 群成员 + 群主/管理员，或开关开启后的普通成员 | 添加群表情 `{media_id, tag?}`；media 必须 kind=emoji 且 ready |
| DELETE | `/emoji/groups/<conv_id>/pack/items/<item_id>/` | 群主/管理员 | 删除群表情（合理闭环；普通成员即使可上传也不可删） |

- 群包幂等：`services.get_or_create_group_pack(conversation)` 按 group 查找/创建（一个群一个包，包名取群标题）；
- 权限服务：`can_view_pack`（群成员可见）、`can_manage_pack`（群主/管理员，或开关开启后的普通成员）、`can_delete_group_item`（群主/管理员）；
- **媒体访问权**（`backend/apps/media/services.py` `can_access_media`）：表情包路径新增群包分支——media 属于某群表情包 → 该群成员可见（否则群成员点开/发送群表情会 403）；
- **上传去重按 kind 区分**（`backend/apps/media/services.py` 上传 complete）：content_hash 去重查询加 `kind` 条件——同一张图先以 image 发过、再以 emoji 传群表情包时，跨 kind 复用会得到 kind=image 的 media，`add_item` 报 `media_type_mismatch`（用户实测发现）；修复后同 hash 同 kind 才复用，不同 kind 各自独立 media。

### 2.3 发送链路（复用，未新增消息类型）

面板点表情 → `sendMessage(convId, "", { type: "emoji", mediaId })` → 现有 `POST /chat/conversations/<id>/messages/`（type=emoji + media_id）→ 全员可见、GIF 动图保真（`MediaContent.tsx` ImageMedia isEmoji 96×96 渲染已存在）。

- **`api/emoji.ts`**（新）：`getGroupEmojiPack` / `setGroupEmojiUploadPolicy` / `addGroupEmojiItem` / `deleteGroupEmojiItem` + `GroupEmojiPackPayload` 类型；

- **样式**：`app.css`（`.composer-tools`、`.emoji-pack-*` 面板系列，宽屏 absolute 向上 / 窄屏 `position: static` 向下展开）+ `group.css`（`.group-info-switch`）。

## 4. 测试

### 后端（`backend/apps/emoji/tests/test_group_emoji_api.py`，6 用例全过）

- 群包可见性（群成员 GET、未创建 404、can_upload/can_delete 按角色）；
- 默认权限：普通成员上传 403、管理员 201；
- 开关：非群主 PATCH 403、群主开启后普通成员可上传、关闭后恢复禁止；
