# Ayla 1.2.4 更新内容

本次修正 1.2.3 里聊天工具栏的几处问题。

## 修复：取消键看不见

- 窄屏下发送中的「取消」键只显示了图标，但图标是空的，
  看起来像个没有任何内容的方块。
- 现在是一个明确的叉号；发送失败的「重试」「删除」也同样补上了图标。

## 修复：别人的消息工具栏离气泡太远

- 别人发的消息，工具栏和气泡之间会空出一段距离。
- 现在工具栏紧贴气泡，和以前一样。

## 修正：只有窄屏才隐藏工具栏文字

- 1.2.3 里判断"空间不够"的方式不对，导致**带侧栏的宽屏窗口**
  也被当成窄屏、只显示了图标。
- 现在只有真正的窄屏才只显示图标；宽屏一律显示「引用」「撤回」文字。

## 说明

- 气泡宽度不再跳变（1.2.3 的修复）依旧有效。
- 完全退出应用后重新打开，新版本才会完全生效。
