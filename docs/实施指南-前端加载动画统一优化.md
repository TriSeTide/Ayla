## 代码要点

### 1. 统一动画原语

```css
/* base.css: 统一入场 */
.reveal { opacity: 0; transform: translateY(8px); }
.reveal.is-in { opacity: 1; transform: translateY(0); transition: opacity 180ms cubic-bezier(0.22,0.61,0.36,1), transform 180ms; }
@media (prefers-reduced-motion: reduce) { .reveal, .reveal.is-in { opacity: 1; transform: none; } }

/* 列表逐条浮入 */
.reveal-item { opacity: 0; animation: reveal-item-in 180ms forwards; animation-delay: var(--reveal-delay, 0ms); }
```

### 2. 帖子详情并行加载

```ts
// 串行 → 并行（Promise.all）
Promise.all([
  postsApi.getPost(id),
  postsApi.listComments(id),
  favoritesApi.listFavorites("post"),
])
```

### 3. 评论实时推送（后端）

```python
# 广播范围 = 帖子可见性对应分组（public→feed 组，group→会话组，friends→作者用户组）
def _comment_audience(post):
    groups = []
    if post.visibility == "public": groups.append(POST_FEED_GROUP)
    if post.group_id: groups.append(f"chat_conv_{post.group_id}")
    if post.owner_id: groups.append(f"chat_user_{post.owner_id}")
    return groups
```
