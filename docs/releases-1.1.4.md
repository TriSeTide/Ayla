# Ayla 1.1.4 更新内容

本次更新为 Ayla 加上了图形标识，并重做了品牌字标。

## 新增：Ayla 图形标识

- 全站品牌位都加上了 Ayla 的图形标识（中心三角 + 三段互锁环形）。
- **登录后加载界面**：标识显示在「Ayla」字标**正上方**、居中排列。
- **其余位置**（登录页左栏、登录卡片、注册页、宽屏顶部导航、桌面端标题栏）：
  标识显示在「Ayla」字标**前面**，横向并排。
- 桌面端标题栏原先是一个粉色小圆点，现同样换成图形标识。

## 变更：品牌字标配色

- 「Ayla」字标改为粉蓝渐变，取自标识自身的配色（冰蓝 → 深粉），
  字标与图标现在完全同色系。
- 渐变中间加入过渡色，避免两色直接相接时中间发灰。
- 字标统一加了细白描边，在浅色背景上更清晰。

## 变更：应用图标

- 桌面端（Windows）图标改用透明底：任务栏在浅色/深色主题下都能正常显示，
  图标内容也更大更清晰。
- 手机端（Android / iOS）图标使用粉色底，与系统圆角蒙版配合更好。

## 说明

- 本次为纯视觉更新，不涉及功能与数据变更。
- 若更新后看不到新标识，请完全退出应用后重新打开。
