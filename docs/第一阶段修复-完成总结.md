### 2️⃣ Store 缓存时间戳机制
**文件**：
- `web/src/stores/chat.ts`
- `web/src/stores/voice.ts`
- `web/src/stores/live.ts`
- `web/src/stores/posts.ts`

**实现**：
- 每个 store 增加 `lastFetched: number` 字段
- 数据加载成功时更新 `lastFetched = Date.now()`
- 导出工具函数 `isXxxStale(maxAge = 60000)`：
  ```typescript
  export function isChatStale(maxAge = 60000): boolean {
    const { lastFetched } = useChatStore.getState();
    return Date.now() - lastFetched > maxAge;
  }
  ```

**页面集成**：
- `VoiceHubPage.tsx`：`if (channels.length > 0 && !isVoiceStale()) return;`
- `LiveHubPage.tsx`：`if (channels.length > 0 && !isLiveStale() && !store.channelsLoading) return;`
- `PostsHubPage.tsx`：`if (posts.length > 0 && !isPostsStale() && !store.loading) return;`
- `HomePage.tsx`：`if (conversations.length > 0 && !isChatStale()) return;`

**解决问题**：
- ✅ 数据最多延迟 60 秒（页面挂载时自动检查过期）
- ✅ 避免频繁重复加载（60 秒内复用缓存）

### 3️⃣ 全局组件按需加载兜底
**文件**：`web/src/components/VisibilitySelector.tsx`（第 29-46 行）

**实现**：
```typescript
useEffect(() => {
  const convs = useChatStore.getState().conversations;
  if (convs.length === 0 && !groupsLoading) {
    setGroupsLoading(true);
    chatApi
      .listConversations()
      .then((list) => useChatStore.getState().setConversations(list))
      .catch((err) => console.error("加载群列表失败", err))
      .finally(() => setGroupsLoading(false));
  }
}, [groupsLoading]);
```

**加载状态**：
- 加载中显示骨架屏：`<div className="visibility-groups-skeleton" />`
- 加载失败显示空态：`<span>没有匹配的群</span>`

**解决问题**：
- ✅ 即使预加载失败，全局组件也能主动加载数据
- ✅ 双重保障：预加载 + 按需加载兜底
