Ayla 1.0.52 更新内容

【手机端 · 点「安装」不再跳浏览器（重要修复）】
- 修复：更新包已经下载完成，点「安装」却跳到浏览器又下载一遍的问题。
- 原因是安装包的新存放位置没有被系统文件共享配置识别，安装器被拒绝后静默改成了「打开下载页」。
- 现在会正常拉起系统安装器；若真的失败，会明确告诉你原因（例如需要允许「安装未知应用」），
  并且**保留下载好的安装包**，可直接重试，不用重新下载。

【存储位置 · 不再占 C 盘】
- 客户端全部本地数据（账号、聊天草稿、媒体缓存、更新包）统一放在程序目录下的 data 文件夹，
  与安装盘一致：装在 D/E 盘就完全不碰 C 盘。
- 更新包下载完会在下次启动时自动清理，只保留当前版本，不再越更新越占空间。
- 如果装在 Program Files 这类受保护目录，数据会自动改存到「用户数据区」下可见的 Ayla\data，
  应用照常使用；不再出现数据散落到隐藏目录、越积越多又找不到的情况。

【说明】
- 本次为纯客户端更新，服务端未变动。
- 建议所有用户更新，尤其是手机端用户。
