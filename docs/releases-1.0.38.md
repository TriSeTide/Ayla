Ayla 1.0.38 更新内容

【悬浮球：真正脱离应用（手机 / 电脑）】
- 原来那个悬浮球（右上角语音/直播球组）现在是**一开始就显示在应用窗口之外**：
  切到别的应用、最小化主窗口，球都还在；点球即可回到对应会话。
- 手机端显示在**其他应用之上**（首次使用需在系统设置里允许「显示在其他应用上层」）；
  电脑端是独立置顶小窗，不进 Alt-Tab 与任务栏，透明背景、只看得见球本身。
- 外观、拖动、收起、点击手感与原来**完全一致**（用的是同一套界面，不是重做的）。
- **应用内不再出现悬浮球**。

【直播小窗：电脑端（新增按钮）】
- 电脑端直播间播放器右下角新增「小窗」键，点它直播就变成**窗口外**的置顶小窗，
  主窗口最小化或被挡住也能继续看，仍然计入在看人数。
- **应用内不再出现直播小窗浮层**。

【直播全屏（手机 + 电脑，重要）】
- 修复电脑端「窗口最大化时点全屏完全没反应」——现在会先解除最大化再进全屏。
- 修复手机端与电脑端「全屏后顶部导航栏仍露在外面」——全屏层之前被放在了导航栏下层。

【说明与已知限制】
- **手机端的直播小窗**：受系统限制，App 退到后台后视频走的是**系统画中画**，
  同时悬浮球组会浮在其他应用之上。它不是「带视频的窗口外小窗」。
  如果这个形态不合适，请告诉我们，我们会评估为它单独引入播放内核。
- 苹果 iOS 受系统限制，不支持跨应用悬浮窗，功能仍留在应用内。

建议所有用户更新。
