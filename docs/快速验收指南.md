## 🆘 遇到问题？

### 问题 1：推送收到但列表不更新

**检查**：
- 打开浏览器 Console，查看是否有错误
- 检查事件类型拼写是否正确（大小写敏感）
- 确认 Store 的方法名正确（`upsertChannel` vs `upsertChannels`）

### 问题 2：列表更新但 UI 不刷新

**检查**：
- 组件是否正确订阅 store：`const channels = useVoiceStore((s) => s.channels)`
- 是否需要手动触发重渲染

### 问题 3：推送根本没收到

**检查**：
- WebSocket 连接是否正常（Network 面板 → WS）
- 后端日志是否有推送成功的记录
- 用户是否在对应的群组中（权限问题）

### 问题 4：图片还是很慢

**检查**：
- 浏览器 Network 面板查看是否有 `Cache-Control` 响应头
- 第二次访问是否显示 `(disk cache)` 或 `304`
- 清除浏览器缓存后重新测试
