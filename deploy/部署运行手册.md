# Ayla 部署运行手册

> 面向 Jetson `ayerelysia`（frp 半容器化）的**完整部署与运维流程**。
> 配置细节见 [README](./README.md)；示例配置见 [`examples/`](./examples/)。
> 相关 skill：`.workbuddy/skills/ayla-deploy`。

## 0. 前置与约定

| 项 | 值 |
| --- | --- |
| SSH | `ssh ayerelysia`（`~/.ssh/config` → `frp.volx.top:6020`） |
| 本地仓库 | `E:/Elysium-AyerElysia/Elysium/Ayla`（分支 `main`） |

> （MSYS 会吞掉 `/tmp/...`）。

## 1. 服务器准备

```bash
# Docker Engine + Compose v2
docker --version && docker compose version

# 部署目录骨架
mkdir -p ~/Elysia/ayla-deploy/{nginx/certs,backend,web}
mkdir -p ~/frp ~/sakurafrp

# frpc 二进制（朋友 + 樱花各一份）
# 朋友：拷 ~/frp/frpc 并配置 ~/frp/frpc.toml（见 examples/frpc.toml.example）
# 樱花：拷 ~/sakurafrp/frpc 并按樱花面板给的 token 启动
```

**Elysium 例外（铁律）**：Elysium 是**宿主进程**，手动启动，监听 `127.0.0.1:18000`，
**容器化/穿透都不要动它**。backend 容器靠 host 网络直连它。

## 2. 代码同步（git bundle）

```bash
# 本地 —— 先查服务器当前 HEAD，只打包差异
cd E:/Elysium-AyerElysia/Elysium/Ayla
git log --oneline -1                      # 本地 HEAD
# （查服务器） ssh ayerelysia 'cd ~/Elysia/Elysium/Ayla && git log --oneline -1'
git bundle create E:/Elysium-AyerElysia/ayla.bundle <serverHead>..main
scp E:/Elysium-AyerElysia/ayla.bundle ayerelysia:/tmp/

# 服务器
cd ~/Elysia/Elysium/Ayla
git fetch /tmp/ayla.bundle main:refs/remotes/origin/main
git merge --ff-only origin/main
rm /tmp/ayla.bundle
git log --oneline -1
```

> 用户负责 `git push` GitHub（本地凭据）。bundle 同步与 push 互不依赖。

## 3. 配置生成

```bash
cd ~/Elysia/ayla-deploy

# 3.1 compose 变量
cp <repo>/deploy/examples/compose.env.example .env
chmod 600 .env
#   逐项填强密码：openssl rand -hex 16

# 3.2 后端环境变量
cp <repo>/deploy/examples/backend.env.example backend/.env
chmod 600 backend/.env
#   注意 DB_PASSWORD / S3_ACCESS_KEY / S3_SECRET_KEY 与 .env 保持一致

# 3.3 nginx / compose / srs
cp <repo>/deploy/examples/nginx.conf.example nginx/nginx.conf
cp <repo>/deploy/examples/docker-compose.yml.example docker-compose.yml
cp <repo>/deploy/examples/srs.conf.example srs.conf

# 校验
docker compose config > /dev/null && echo "compose OK"
```

## 5. 前端构建与部署

```bash
# ---- 本地 ----
cd E:/Elysium-AyerElysia/Elysium/Ayla/web
pnpm exec vite build --outDir dist-new --emptyOutDir false
# ⚠️ 沙箱里 vite emptyOutDir 会超时（genie-safe-delete）→ 用 outDir 绕开；
#    切勿直接覆盖 dist
tar -czf dist-new.tgz -C dist-new .
scp dist-new.tgz ayerelysia:/tmp/

# ---- 服务器：原地替换（绝不能 mv dist dist.bak && mkdir dist）----
cd ~/Elysia/ayla-deploy/web
rm -rf dist/assets dist/index.html       # 只删内容，保留 dist 目录本身
tar -xzf /tmp/dist-new.tgz -C dist
# 验证要**站在容器视角**：
docker exec ayla-nginx sh -c 'grep -o "index-[A-Za-z0-9_-]*\.js" /usr/share/nginx/html/index.html'
```

## 6. 启动与验收

```bash
cd ~/Elysia/ayla-deploy

docker compose up -d
docker compose ps                       # 期望：mysql/redis/minio/srs healthy，backend/nginx Up

# 迁移（首次或模型变更）
docker compose exec backend python manage.py migrate

# 静态（如启用 collectstatic）
docker compose exec backend python manage.py collectstatic --noinput
```

**验收清单**

```bash
# 1) 本机入口
curl -kI https://127.0.0.1:443/            # 200
curl -k  https://127.0.0.1:8443/live/x.m3u8  # 404（隔离正确，非 200）

# 2) WS 路由探针（403=路由在+鉴权拒；500=无此路由）
K=dGhlIHNhbXBsZSBub25jZQ==
curl -s -o /dev/null -w "%{http_code}\n" \
  -H "Connection: Upgrade" -H "Upgrade: websocket" \
  -H "Sec-WebSocket-Key: $K" -H "Sec-WebSocket-Version: 13" \
  "http://127.0.0.1:8100/ws/voice/audio/?token=x&channel=1"

# 3) 公网入口（本地核验务必 --noproxy '*'，否则被沙箱代理误导）
curl -k -s --noproxy '*' -o /dev/null -w "sakura=%{http_code}\n" https://frp-one.com:26211/
curl -s   --noproxy '*' -o /dev/null -w "cf=%{http_code}\n"     https://ayla.trise.top/
curl -k -s --noproxy '*' -o /dev/null -w "pull=%{http_code}\n"  https://live.trise.top:7882/live/x.m3u8

# 4) 前端 hash 与本地构建一致
curl -s --noproxy '*' https://ayla.trise.top/ | grep -o "index-.*\.js"
```

## 7. 穿透（frpc）

```bash
# 朋友 frp
cd ~/frp && setsid nohup ./frpc -c frpc.toml >> frpc.log 2>&1 < /dev/null &

# 樱花 frp
cd ~/sakurafrp && setsid nohup ./frpc -f <SAKURA_TOKEN> >> frpc-sakura.log 2>&1 < /dev/null &

# 守护：cron 每分钟跑 keepalive.sh（见 examples/keepalive.sh.example）
crontab -l | grep keepalive || (crontab -l; echo "* * * * * /home/ayerelysia/frp/keepalive.sh") | crontab -
```

## 8. 日常运维

| 场景 | 命令 |
| --- | --- |
| **改前端** | §5 构建 → 原地替换 dist → `docker exec ayla-nginx nginx -s reload`（可选） |
| **改后端代码** | §2 bundle 同步 → §4 重建镜像 → `docker compose up -d --no-deps backend` |
| **改 backend/.env** | `docker compose up -d --no-deps backend`（**必须 up，restart 不重读**） |
| **改 nginx.conf** | `docker exec ayla-nginx nginx -t` → `nginx -s reload`（**原地覆盖保 inode**） |
| **改 docker-compose.yml** | `docker compose config` → `docker compose up -d` |
| **改 frpc.toml** | 重启对应 frpc 进程 |
| **看日志** | `docker compose logs -f --tail=100 backend` / `~/frp/frpc.log` |
| **回滚** | 前端：重新部署旧 dist；后端：`docker tag` 旧镜像后 `up`；配置：切 `*.bak-*` |

**备份**

```bash
# MySQL
docker compose exec mysql mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" --all-databases > ~/backup/db.sql
# MinIO
docker run --rm -v ayla-deploy_minio_data:/data -v ~/backup:/backup alpine \
  tar czf /backup/minio.tgz -C /data .
# Media（MinIO 桶内对象）/ 数据库 建议纳入定时任务
```

**证书续签**：见 README §7 与 [`examples/acme-cert-renew.sh.example`](./examples/acme-cert-renew.sh.example)。

## 9. 故障排查速查

| 现象 | 首查 |
| --- | --- |
| 网页打不开（26211） | 樱花 frpc 是否活（`pgrep -f sakurafrp`）；证书是否过期 |
| 网页打不开（ayla.trise.top） | CF Tunnel 是否在跑；`docker exec ayla-nginx nginx -t` |
| 改了配置没生效 | **inode 陷阱**：是否用 `mv` 换了源文件 |
| 拉流 404 | `SRS_PLAY_URL` 是否 7882；nginx 8443 块是否命中正则 |
| 语音连不上 | `wss://live.trise.top:7881` 隧道；nginx 443；daphne 8100；token 是否过期 |
| 后端 503（语音 join） | LiveKit 已退役——若仍返回“LiveKit 未配置”，说明代码是旧版 |
| 本地 curl 报 502/timeout | **沙箱代理污染**：加 `--noproxy '*'` 重测 |
| DNS 不生效 | 是否加在了阿里云（错）——权威在 Cloudflare |
